คำใบ้

แนวคิดและเฉลยแบบละเอียด

แนวคิด: เวกเตอร์พิกัด = สัมประสิทธิ์ในการรวมเชิงเส้น — ตั้งระบบแล้วแก้

  1. ตั้งระบบ \(c_1\begin{bmatrix}1\\-4\end{bmatrix} + c_2\begin{bmatrix}-2\\7\end{bmatrix} = \begin{bmatrix}-3\\7\end{bmatrix}\) → \(c_1 - 2c_2 = -3\), \(-4c_1 + 7c_2 = 7\)
  2. แก้ จากสมการแรก \(c_1 = 2c_2 - 3\) แทนสมการที่สอง: \(-4(2c_2-3) + 7c_2 = 7\) → \(-8c_2 + 12 + 7c_2 = 7\) → \(-c_2 = -5\) → \(c_2 = 5\), \(c_1 = 7\)
  3. ตรวจคำตอบ \(7(1,-4) + 5(-2,7) = (7-10, -28+35) = (-3, 7)\) ✓ — สรุป: \([\vec{x}]_B = \begin{bmatrix} 7\\ 5 \end{bmatrix}\)

  3. ตรวจคำตอบ สมการ 3: \(-3(\frac{7}{4}) - 5(-\frac{5}{4}) = \frac{-21+25}{4} = 1\) ✓ — สรุป: \([\vec{x}]_B = \begin{bmatrix} \frac{7}{4}\\ -\frac{5}{4} \end{bmatrix}\) (ตรงคำตอบท้ายบท)
แบบฝึกหัด 3.1 ข้อ 2●●○

จงแสดงว่า \(B' = \left\{\begin{bmatrix} 1\\ 2\\ 0 \end{bmatrix}, \begin{bmatrix} 0\\ 1\\ 0 \end{bmatrix}, \begin{bmatrix} -1\\ 1\\ 3 \end{bmatrix}\right\}\) เป็นฐานหลักสำหรับ \(\mathbb{R}^3\) และจงหาเมทริกซ์การเปลี่ยนพิกัดจากฐานหลักมาตรฐาน \(B = \{\vec{e}_1, \vec{e}_2, \vec{e}_3\}\) ไป B′ พร้อมทั้งหา \([\vec{v}]_{B'}\) เมื่อ \(\vec{v} = \begin{bmatrix} 0\\ 3\\ 3 \end{bmatrix}\)

คำใบ้
เมทริกซ์เปลี่ยนพิกัดจากมาตรฐานไป B′ = \(P = [\vec{b}'_1\ \vec{b}'_2\ \vec{b}'_3]\) — แสดงฐานหลักด้วย det ≠ 0 · \([\vec{v}]_{B'} = P^{-1}\vec{v}\)
แนวคิดและเฉลยแบบละเอียด

แนวคิด: หลักของ P คือเวกเตอร์ฐานหลัก B′ — P ไม่เอกฐาน ⟺ เป็นฐานหลัก และ \(P[\vec{v}]_{B'} = \vec{v}\) จึงแก้ด้วย \(P^{-1}\)

  1. แสดงว่าเป็นฐานหลัก \(P = \begin{bmatrix} 1 & 0 & -1\\ 2 & 1 & 1\\ 0 & 0 & 3 \end{bmatrix}\) → \(\det P = 3(1\cdot1 - 0\cdot2) = 3 \neq 0\) → 3 เวกเตอร์อิสระใน \(\mathbb{R}^3\) = ฐานหลัก ∎
  2. เมทริกซ์เปลี่ยนพิกัด B→B′ คอลัมน์ที่ j = \([\vec{e}_j]_{B'}\) — รวมได้ว่าเมทริกซ์นี้คือ \(P^{-1}\) (เพราะ \(P[\vec{e}_j]_{B'} = \vec{e}_j\)) — หาโดยแถวดำเนินการ \([P \mid I] \to [I \mid P^{-1}]\) ได้ \(P^{-1} = \begin{bmatrix} 1 & 0 & \frac{1}{3}\\ -2 & 1 & -1\\ 0 & 0 & \frac{1}{3} \end{bmatrix}\)
  3. หา [v]B′ \([\vec{v}]_{B'} = P^{-1}\vec{v} = \begin{bmatrix} 0+\frac{3}{3}\\ -2+3-3\\ \frac{3}{3} \end{bmatrix} = \begin{bmatrix} 1\\ 0\\ 1 \end{bmatrix}\)
  4. ตรวจคำตอบ \(1\vec{b}'_1 + 0\vec{b}'_2 + 1\vec{b}'_3 = (1,2,0)+(-1,1,3) = (0,3,3) = \vec{v}\) ✓ — สรุป: \(P\) เป็นฐานหลัก (det = 3), เมทริกซ์เปลี่ยนพิกัด \(= P^{-1}\) ตามด้านบน, \([\vec{v}]_{B'} = (1, 0, 1)\) (ตรงคำตอบท้ายบท)

จงแสดงว่า ถ้าเมทริกซ์ A คล้ายกับเมทริกซ์ B แล้ว \(A^T\) คล้ายกับ \(B^T\)

คำใบ้
นิยามคล้าย: \(B = P^{-1}AP\) — ถอดทรานสโพสทั้งสมการแล้วจัดรูป
แนวคิดและเฉลยแบบละเอียด

แนวคิด: ต้องหาเมทริกซ์ "สะพาน" ใหม่ที่พา \(A^T\) ไป \(B^T\) — ตัวสะพานคือ \((P^{-1})^T\)

  1. เริ่มจากนิยาม A คล้าย B → มี P ไม่เอกฐานที่ \(P^{-1}AP = B\)
  2. ถอดทรานสโพส \((P^{-1}AP)^T = B^T\) → \(P^TA^T(P^{-1})^T = B^T\)
  3. จัดรูป \((P^{-1})^TP^T = (PP^{-1})^T = I\) → \(A^T = (P^T)^{-1}B^T(P^{-1})^T\)... จัดให้อยู่รูป "สะพานหน้า-หลัง": ให้ \(Q = (P^T)^{-1}\) (ไม่เอกฐาน) แล้ว \(Q^{-1}B^TQ = P^TB^T(P^T)^{-1}\)? — ทำตรงจากขั้น 2: \(B^T = P^TA^T(P^T)^{-1}\)? ตรวจ: \((P^{-1})^T = (P^T)^{-1}\) → ขั้น 2 กลายเป็น \(P^TA^T(P^T)^{-1} = B^T\) — นี่คือ \(B^T = Q A^T Q^{-1}\) กับ \(Q = P^T\) หรือเทียบเท่า \(A^T = Q^{-1}B^TQ\) → \(A^T\) คล้าย \(B^T\) ∎
  4. ตรวจคำตอบ โครงสร้างสำคัญ: \((P^{-1}AP)^T = P^TA^T(P^{-1})^T\) และ \((P^{-1})^T = (P^T)^{-1}\) — สองเอกลักษณ์นี้คือทั้งหมดของข้อนี้ ✓

คำใบ้
ใช้ P, D เดิม: \(A = PDP^{-1}\) → \(A^{-1} = PD^{-1}P^{-1}\) — อินเวอร์สของทแยงมุมก็ยังทแยงมุม
แนวคิดและเฉลยแบบละเอียด

แนวคิด: "ใช้สะพาน P เดิม" — เพียงแต่ D เปลี่ยนเป็น D⁻¹

  1. สมมติฐาน A ทแยงมุมได้ → มี P ไม่เอกฐาน, D ทแยงมุม: \(P^{-1}AP = D\)
  2. อินเวอร์ส A ไม่เอกฐาน → ทุก λ บนทแยงของ D ไม่เป็นศูนย์ → \(D^{-1}\) มีอยู่ (ทแยงด้วย \(1/\lambda_i\)) และ \(A^{-1} = (PDP^{-1})^{-1} = PD^{-1}P^{-1}\) (ใช้ \((ABC)^{-1} = C^{-1}B^{-1}A^{-1}\))
  3. สรุป \(A^{-1} = PD^{-1}P^{-1}\) โดย \(D^{-1}\) ทแยงมุม → \(A^{-1}\) ทแยงมุมได้ ∎ — ค่าลักษณะเฉพาะของ \(A^{-1}\) คือ \(1/\lambda_i\) กับเวกเตอร์ลักษณะเฉพาะตัวเดิม
  4. ตรวจคำตอบ ตัวอย่างตรวจสอบ: \(A = \begin{bmatrix} 2 & 2\\ 2 & -1 \end{bmatrix}\) (ข้อ 4 ก): \(A^{-1} = \frac{1}{-6}\begin{bmatrix} -1 & -2\\ -2 & 2 \end{bmatrix}\) และ \(D^{-1} = \mathrm{diag}(1/3, -1/2)\) — แทนใน \(PD^{-1}P^{-1}\) ได้ \(A^{-1}\) ตรง ✓
แบบฝึกหัด 3.2 ข้อ 10●●○

จงแสดงว่า A เป็นเมทริกซ์เอกฐาน ก็ต่อเมื่อ 0 เป็นค่าลักษณะเฉพาะของเมทริกซ์ A

คำใบ้
"ก็ต่อเมื่อ" = พิสูจน์สองทิศ — เครื่องมือ: เอกฐาน ⟺ det A = 0 และ λ เป็นค่าลักษณะเฉพาะ ⟺ det(A−λI) = 0
แนวคิดและเฉลยแบบละเอียด

แนวคิด: สองทิศผ่าน det ล้วน ๆ

  1. ทิศ (⇒) A เอกฐาน → \(\det A = 0\) → \(\det(A-0\cdot I) = \det A = 0\) → 0 เป็นค่าลักษณะเฉพาะ (เกณฑ์ det(A−λI) = 0 ที่ λ = 0) ✓
  2. ทิศ (⇐) 0 เป็นค่าลักษณะเฉพาะ → \(\det(A-0\cdot I) = \det A = 0\) → A เอกฐาน ✓
  3. สรุป จริงสองทิศ → "A เอกฐาน ก็ต่อเมื่อ 0 เป็นค่าลักษณะเฉพาะ" ∎ — เกร็ดข้อสอบ: เทียบเท่ากับ "A ไม่เอกฐาน ⟺ ค่าลักษณะเฉพาะทุกตัวไม่เป็นศูนย์"
แบบฝึกหัด 3.2 ข้อ 11●●●

จงยกตัวอย่างเมทริกซ์ A และ B มิติ \(2 \times 2\) ซึ่งมีค่าลักษณะเฉพาะชุดเดียวกัน แต่เมทริกซ์ A ไม่คล้ายกับเมทริกซ์ B

คำใบ้
ใช้เมทริกซ์จากข้อ 4 (ข) และ (ง) — ทั้งคู่มี λ ซ้ำแต่ eigenspace มิติเดียว
แนวคิดและเฉลยแบบละเอียด

แนวคิด: ค่าลักษณะเฉพาะชุดเดียวกันไม่การันตีการคล้าย — เอาคู่ที่ λ ซ้ำทั้งคู่แต่ไม่คล้าย I (เพราะถ้าคล้าย I ต้องเท่า I เท่านั้น!)

  1. ตัวอย่าง จากข้อ 4: \(A = \begin{bmatrix} 14 & 16\\ -9 & -10 \end{bmatrix}\) และ \(B = \begin{bmatrix} 5 & 4\\ -1 & 1 \end{bmatrix}\) — ทั้งคู่มีค่าลักษณะเฉพาะ \(\lambda = 2, 2\) (จากการคำนวณในข้อ 4 ข และ ง)
  2. พิสูจน์ไม่คล้าย สมมติ A คล้าย B → มี P ที่ \(B = P^{-1}AP\) จากนั้น... ใช้ข้อสังเกตที่แรงกว่า: ถ้าเมทริกซ์คล้ายกับ \(\begin{bmatrix} 2 & 0\\ 0 & 2 \end{bmatrix} = 2I\) จะได้เมทริกซ์ = \(2I\) เสมอ (เพราะ \(P^{-1}(2I)P = 2I\)) — แต่ A คล้าย \(2I\) หรือไม่: ถ้า A คล้าย 2I แล้ว A = 2I ซึ่งเป็นเท็จ → A ไม่คล้าย 2I; เหตุผลโดยตรงระหว่าง A กับ B: A และ B ต่างไม่ทแยงมุมได้ (eigenspace มิติเดียวทั้งคู่) — ใช้เกณฑ์: เมทริกซ์ที่คล้ายกันต้องมี rank เท่ากัน, trace เท่ากัน, det เท่ากัน — ตัวที่แยกชัดที่สุด: เลือก B เป็น \(2I\) เอง! แต่ λ(2I) = 2, 2 เท่ากับของ A ✓ และ A ไม่คล้าย \(2I\) เพราะถ้าคล้ายจะได้ \(A = 2I\) (ขัดแย้ง) — นี่คือตัวอย่างที่สะอาดที่สุด
  3. สรุป \(A = \begin{bmatrix} 14 & 16\\ -9 & -10 \end{bmatrix}\), \(B = \begin{bmatrix} 2 & 0\\ 0 & 2 \end{bmatrix}\): λ เหมือนกันทั้งคู่ (2, 2) แต่ A ไม่คล้าย B ∎ เหตุผล: ถ้า A = P⁻¹(2I)P = 2I สำหรับ P ใด ๆ (คูณเมทริกซ์ I สลับที่ได้ตัวมันเอง) ขัดแย้งกับ A จริง ✓ (ตรวจ: λ ของ A จากข้อ 4 (ข) = 2, 2 ✓)

คำใบ้
เขียนเป็นผลรวมสองชั้นแล้วสลับลำดับการบวก
แนวคิดและเฉลยแบบละเอียด

แนวคิด: \(\mathrm{tr}(M) = \sum_i m_{ii}\) — คำนวณช่องทแยงของ AB และ BA แล้วเทียบ

  1. เขียนผลรวม \(\mathrm{tr}(AB) = \sum_{i=1}^{n}(AB)_{ii} = \sum_{i=1}^{n}\sum_{j=1}^{n}a_{ij}b_{ji}\)
  2. สลับ \(\mathrm{tr}(BA) = \sum_{i=1}^{n}(BA)_{ii} = \sum_{i=1}^{n}\sum_{j=1}^{n}b_{ij}a_{ji} = \sum_{i=1}^{n}\sum_{j=1}^{n}a_{ji}b_{ji}\)? — เขียนให้ชัด: ในนิพจน์ของ tr(AB) สลับชื่อดัชนี \(i \leftrightarrow j\): \(\sum_{j}\sum_{i}a_{ji}b_{ij} = \sum_i (BA)_{ii} = \mathrm{tr}(BA)\) ∎ (การสลับดัชนีทำได้เพราะเป็นผลรวมจำกัด)
  3. ตรวจคำตอบ ตัวอย่าง 2×2: \(AB = \begin{bmatrix} 1 & 2\\ 0 & 3 \end{bmatrix}\begin{bmatrix} 4 & 0\\ 1 & 5 \end{bmatrix} = \begin{bmatrix} 6 & 10\\ 3 & 15 \end{bmatrix}\) tr = 21; \(BA = \begin{bmatrix} 4 & 8\\ 1 & 17 \end{bmatrix}\) tr = 21 ✓

จงแสดงว่า ถ้า \(A = \begin{bmatrix} a & b\\ c & d \end{bmatrix}\) แล้วพหุนามลักษณะเฉพาะของ A คือ \(\lambda^2 - (\mathrm{tr}\,A)\lambda + \det A\)

แนวคิดและเฉลยแบบละเอียด

แนวคิด: คำนวณตรง แล้วจำสูตรนี้ให้ขึ้นใจ — ใช้เช็กคำตอบสมการลักษณะเฉพาะ 2×2 ได้ตลอด (trace ลบ λ + det)

  2. จัดรูป \(= ad - a\lambda - d\lambda + \lambda^2 - bc = \lambda^2 - (a+d)\lambda + (ad-bc) = \lambda^2 - (\mathrm{tr}\,A)\lambda + \det A\) ∎ (เพราะ \(\mathrm{tr}\,A = a+d\), \(\det A = ad-bc\))
  3. ตรวจคำตอบ ใช้กับข้อ 4 (ก): \(A = \begin{bmatrix} 2 & 2\\ 2 & -1 \end{bmatrix}\): \(\lambda^2 - (1)\lambda + (-6) = 0\) ✓ ตรงกับที่คำนวณ — จำสูตร: พหุนามลักษณะเฉพาะของ 2×2 = \(\lambda^2 - (\mathrm{tr})\lambda + \det\)
