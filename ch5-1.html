5.1 ปริภูมิเวกเตอร์และปริภูมิย่อย

ยกระดับ "เวกเตอร์" ให้เป็นนามธรรม — พหุนาม เมทริกซ์ ฟังก์ชัน ก็เป็นเวกเตอร์ได้ทั้งหมด ทุกทฤษฎีจากบทที่ 1–2 (Span, อิสระเชิงเส้น, ฐานหลัก, มิติ) ใช้ได้กับปริภูมิเหล่านี้ทันที

🎯 จุดประสงค์ 📖 บทเรียน ✏️ ตัวอย่างโจทย์ 📚 ตัวอย่างจากตำรา 🌍 การใช้จริง ⚡ สูตรสำเร็จ 🏋️ โจทย์ซ้อมมือ

🎯 เรียนจบหัวข้อนี้ คุณต้องทำสิ่งเหล่านี้ได้

  • บอกตัวอย่างปริภูมิเวกเตอร์ที่สำคัญ: \(\mathbb{F}^n\), \(M_{m,n}(\mathbb{F})\), \(\mathbb{F}_n[x]\), \(\mathbb{F}[x]\), ปริภูมิฟังก์ชัน, ปริภูมิลำดับ
  • ตรวจว่าเซตย่อย (พร้อมการดำเนินการที่กำหนดให้) เป็นปริภูมิเวกเตอร์หรือปริภูมิย่อยหรือไม่
  • ใช้เกณฑ์ปริภูมิย่อย: \(\vec{0} \in W\) และ \(\vec{v}_1 + c\vec{v}_2 \in W\)
  • ตรวจอิสระเชิงเส้น/Span/ฐานหลักใน \(\mathbb{F}_n[x]\) และ \(M_{m,n}(\mathbb{F})\) และหามิติ: \(\dim M_{m,n} = mn\), \(\dim \mathbb{F}_n[x] = n+1\)
  • หาฐานหลักและมิติของ \(W_1 + W_2\) และ \(W_1 \cap W_2\)

📖 บทเรียน

1) ปริภูมิเวกเตอร์ (vector space)

📐 นิยาม (โดยสรุป)

ปริภูมิเวกเตอร์ \((V, \oplus, \odot)\) เหนือฟีลด์ \(\mathbb{F}\) คือเซต \(V\) พร้อมการบวก \(\oplus\) และการคูณสเกลาร์ \(\odot\) ที่สอดคล้องสมบัติ: การบวกปิด/เปลี่ยนหมู่/มีเอกลักษณ์ \(\vec{0}_V\)/สลับที่/มีตัวผกผัน และสมบัติการคูณสเกลาร์ 4 ข้อ (รวมถึง \(1 \odot \vec{v} = \vec{v}\))

ทฤษฎีบท 5.1.1 ให้สมบัติตามมา: \(0\odot\vec{v} = \vec{0}_V\), \((-1)\odot\vec{v} = -\vec{v}\), \(c\odot\vec{0}_V = \vec{0}_V\) — เครื่องมือตรวจ "ไม่ใช่ปริภูมิเวกเตอร์" ที่เร็วที่สุดคือหา \(\vec{0}_V\) หรือเช็ก \(1\odot\vec{v} = \vec{v}\)

💡 ตัวอย่างปริภูมิเวกเตอร์ที่ต้องรู้จัก

• \(\mathbb{F}^n\), \(M_{m,n}(\mathbb{F})\) (เมทริกซ์ \(m\times n\)) — เหมือนบทที่ 1

• \(\mathbb{F}_n[x]\) = พหุนามดีกรีไม่เกิน \(n\) เช่น \(\mathbb{R}_2[x] = \{a_0 + a_1x + a_2x^2\}\) — เปรียบเทียบได้กับ \(\mathbb{F}^{n+1}\) ผ่านสัมประสิทธิ์

• \(\mathbb{F}[x]\) = พหุนามทุกดีกรี (มีมิติไม่จำกัด), ปริภูมิฟังก์ชัน \(\mathbb{R}^{\mathbb{R}}\), ปริภูมิลำดับ \(\mathbb{F}^{\mathbb{N}}\), ผลคูณตรง \(V_1\times\cdots\times V_n\)

2) ปริภูมิย่อย (subspace)

⭐ ทฤษฎีบท 5.1.3 — เกณฑ์ปริภูมิย่อย (ใช้บ่อยที่สุดของบทนี้)

\(W \subseteq V\) เป็นปริภูมิย่อยของ \(V\) ก็ต่อเมื่อ

1. \(\vec{0}_V \in W\)  และ  2. \(\vec{v}_1 + c\vec{v}_2 \in W\) สำหรับทุก \(\vec{v}_1, \vec{v}_2 \in W\), \(c \in \mathbb{F}\) (ปิดการรวมเชิงเส้น)

3) Span อิสระเชิงเส้น ฐานหลัก มิติ — ใช้ได้กับทุกปริภูมิ

⭐ ความรู้เดิม ใช้ใหม่ได้ทันที

Span, อิสระเชิงเส้น, ฐานหลัก (อิสระ + แผ่ทั่ว), มิติ (ฐานหลักทุกอันมีขนาดเท่ากัน — ทฤษฎีบท 5.1.5) นิยามเหมือนบทที่ 1–2 เพียงแต่เวกเตอร์อาจเป็นพหุนาม/เมทริกซ์/ฟังก์ชัน

• \(\dim M_{m,n}(\mathbb{F}) = mn\) (ฐานหลักมาตรฐาน = เมทริกซ์ \(E_{ij}\) ที่มี 1 ตำแหน่ง \((i,j)\))

• \(\dim \mathbb{F}_n[x] = n + 1\) (ฐานหลักมาตรฐาน \(\{1, x, x^2, \dots, x^n\}\))

• \(\mathbb{F}[x]\) มีมิติไม่จำกัด

📐 ผลบวกและภาวะเชิงตัดของปริภูมิย่อย (ทฤษฎีบท 5.1.6)

ถ้า \(W_1, W_2\) เป็นปริภูมิย่อยของ \(V\) แล้ว \(W_1 + W_2 = \{\vec{w}_1 + \vec{w}_2\}\) และ \(W_1 \cap W_2\) เป็นปริภูมิย่อยของ \(V\) ทั้งคู่ และสำหรับมิติจำกัด:

\[ \dim(W_1 + W_2) = \dim W_1 + \dim W_2 - \dim(W_1 \cap W_2) \]
⚠️ กับดักของบทนี้

• เจอการบวก/การคูณสเกลาร์ที่กำหนดให้แปลก ๆ ต้องเช็กสมบัติตามนิยามจริง ๆ ห้ามสันนิษฐาน — จุดพังบ่อย: ไม่มี \(\vec{0}_V\), \(1\odot\vec{v} \neq \vec{v}\), หรือ \((c_1+c_2)\odot\vec{v} \neq c_1\odot\vec{v} \oplus c_2\odot\vec{v}\)

• เงื่อนไขเชิงพีชคณิตแบบ "ไม่เชิงเส้น" (เช่น \(\det A = 0\), \(p(0) = 1\)) มักไม่เป็นปริภูมิย่อย เพราะไม่ปิดการบวก — หาเวกเตอร์ตัวอย่างค้านได้เร็ว

✏️ ตัวอย่างโจทย์

ตัวอย่าง 1ง่ายตรวจปริภูมิย่อยของ \(\mathbb{R}[x]\) (ตัวอย่างคลาสสิกของตำรา)
จงพิจารณาว่า \(W_1 = \{p(x) \in \mathbb{R}[x] : p(1) = 0\}\) และ \(W_2 = \{p(x) \in \mathbb{R}[x] : p(0) = 1\}\) เป็นปริภูมิย่อยของ \(\mathbb{R}[x]\) หรือไม่ เพราะเหตุใด
แนวคิด — เช็ก \(\vec{0}\) ก่อน แล้วเช็กการปิดการรวมเชิงเส้น กลยุทธ์ของข้อนี้คือใช้เกณฑ์ปริภูมิย่อย (ทฤษฎีบท 5.1.3) ที่ต้องผ่านสองข้อติดกัน: (1) เวกเตอร์ศูนย์อยู่ในเซต และ (2) ปิดการรวมเชิงเส้น — ข้อใดพังข้อเดียวก็ตอบได้ทันทีว่า "ไม่เป็น" โดยไม่ต้องเช็กข้อที่เหลือ สังเกตด้วยว่าเงื่อนไขแบบ \(p(1) = 0\) คือ "แทนค่าแล้วต้องได้ศูนย์" ซึ่งเป็นเงื่อนไขเชิงเส้น (ค่าที่จุดเดียวกันบวก/คูณสเกลาร์กันได้ตรง ๆ) จึงมักผ่านทั้งสองข้อ ส่วนเงื่อนไขแบบ \(p(0) = 1\) บังคับให้ค่าที่จุดนั้นเท่ากับค่าคงที่ที่ไม่ใช่ศูนย์ ซึ่งมักพังตั้งแต่ข้อ (1) เพราะพหุนามศูนย์แทนค่าได้ 0 เสมอ
  1. เตรียมเครื่องมือ: เกณฑ์ปริภูมิย่อย (ทฤษฎีบท 5.1.3) \(W \subseteq V\) เป็นปริภูมิย่อยของ \(V\) ก็ต่อเมื่อ (1) \(\vec{0}_V \in W\) และ (2) \(\vec{v}_1 + c\vec{v}_2 \in W\) สำหรับทุก \(\vec{v}_1, \vec{v}_2 \in W\) และสเกลาร์ \(c\) ทุกค่า (ข้อ (2) เรียกว่า "ปิดการรวมเชิงเส้น" = จับสมาชิกในเซตมาบวกกัน/คูณสเกลาร์แล้วผลลัพธ์ต้องไม่หลุดออกนอกเซต) — เราจะเช็กสองข้อนี้กับ \(W_1\) และ \(W_2\) ทีละตัว
  2. \(W_1\): เช็กข้อ (1) เวกเตอร์ศูนย์ เวกเตอร์ศูนย์ของ \(\mathbb{R}[x]\) คือพหุนามศูนย์ \(p(x) = 0\) (พหุนามที่สัมประสิทธิ์ทุกตัวเป็นศูนย์) แทนค่าที่ \(x = 1\): พหุนามศูนย์มี \(p(1) = 0\) ✓ ตรงเงื่อนไข \(p(1) = 0\) พอดี (เพราะพหุนามศูนย์ให้ค่า 0 ที่ทุกจุด) → \(\vec{0} \in W_1\) ✓ ผ่านข้อแรก
  3. \(W_1\): เช็กข้อ (2) ปิดการรวมเชิงเส้น ให้ \(p, q \in W_1\) ใด ๆ — แปลว่า \(p(1) = q(1) = 0\) — และ \(c \in \mathbb{R}\) ใด ๆ แล้วพิจารณา \(p + cq\) ที่ \(x = 1\) (ใช้สมบัติ "การแทนค่ากระจายผ่านการบวกและการคูณสเกลาร์" ของพหุนาม): \[ (p + cq)(1) = p(1) + cq(1) = 0 + c \cdot 0 = 0 \;\checkmark \] เพราะเงื่อนไขของ \(W_1\) เป็นเพียง "แทนค่าที่จุดเดียวแล้วเท่ากับ 0" ซึ่งรักษาตัวเองไว้ภายใต้การบวก/คูณสเกลาร์ → \(p + cq \in W_1\) → ปิดการรวมเชิงเส้น ✓
  4. สรุป \(W_1\) ผ่านทั้งสองข้อของเกณฑ์ (ทฤษฎีบท 5.1.3) → \(W_1\) เป็นปริภูมิย่อยของ \(\mathbb{R}[x]\) (ทดลองด้วยตัวอย่างจริง: \(p(x) = x - 1\) มี \(p(1) = 0\) จริง และ \(2p\) ก็ยังมี \((2p)(1) = 0\) ไม่หลุดเซต)
  5. \(W_2\): เช็กข้อ (1) พังทันที เงื่อนไขของ \(W_2\) คือ \(p(0) = 1\) แต่พหุนามศูนย์ \(p(x) = 0\) ให้ \(p(0) = 0 \neq 1\) (สัญลักษณ์ \(\neq\) อ่านว่า "ไม่เท่ากับ") → \(\vec{0} \notin W_2\) ✗ เพราะปริภูมิย่อยทุกอันต้องมีเวกเตอร์ศูนย์เป็นสมาชิก (ข้อ (1) ของทฤษฎีบท 5.1.3) → \(W_2\) ไม่เป็นปริภูมิย่อย — จบการพิสูจน์ได้ตรงนี้เลย ไม่ต้องเช็กข้อ (2)
  6. (เสริม) แม้แต่ข้อ (2) ของ \(W_2\) ก็พังเช่นกัน ถ้า \(p, q \in W_2\) (คือ \(p(0) = q(0) = 1\)) แล้ว \[ (p + q)(0) = p(0) + q(0) = 1 + 1 = 2 \neq 1 \] ผลบวกหลุดออกจาก \(W_2\) ทันที (สังเกตว่า "1 + 1 = 2 ไม่ใช่ 1" — เงื่อนไขค่าคงที่ที่ไม่ใช่ศูนย์ไม่มีทางปิดการบวก เพราะการบวกกันสองครั้งทำให้ค่าเพิ่มเป็นสองเท่าเสมอ) — ยืนยันอีกชั้นว่า \(W_2\) ไม่เป็นปริภูมิย่อย
ตัวอย่าง 2ง่ายตรวจปริภูมิย่อยของ \(M_2(\mathbb{R})\) (ตัวอย่างคลาสสิกของตำรา)
จงพิจารณาว่า \(W = \{A \in M_2(\mathbb{R}) : A \text{ เป็นเมทริกซ์สมมาตร}\}\) และ \(U = \{A \in M_2(\mathbb{R}) : \det A = 0\}\) เป็นปริภูมิย่อยของ \(M_2(\mathbb{R})\) หรือไม่
แนวคิด — เงื่อนไขเชิงเส้น → ปริภูมิย่อย / เงื่อนไขเชิงคูณ (det, กำลังสอง) → มักพังการบวก กลยุทธ์ของข้อนี้: เงื่อนไข "สมมาตร" (\(A^T = A\)) เทียบสมาชิกตำแหน่งกระจกโดยตรง ไม่มีการคูณสมาชิกเข้าด้วยกัน จึงเป็นเงื่อนไขเชิงเส้นและมักผ่านเกณฑ์สองข้อ ส่วนเงื่อนไข \(\det A = 0\) มาจากสูตร \(ad - bc\) ที่คูณสมาชิกเข้าด้วยกัน (ไม่เชิงเส้น) — เคล็ดลับ: ถ้าสงสัยว่าเซตไม่เป็นปริภูมิย่อย ให้รีบหาตัวอย่างค้านคือสมาชิกสองตัวในเซตที่ผลบวกหลุดออกนอกเซต โดยใช้เมทริกซ์ทแยงที่มี 0 เยอะ ๆ เป็นตัวช่วยคิดเร็วที่สุด
  1. เตรียมนิยามที่ใช้ เมทริกซ์สมมาตร = เมทริกซ์ \(A\) ที่ \(A^T = A\) โดย \(A^T\) (ทรานสโพส) คือการสลับแถวกับหลัก เช่น \(\begin{bmatrix} a & b\\ c & d \end{bmatrix}^T = \begin{bmatrix} a & c\\ b & d \end{bmatrix}\) — เมทริกซ์ \(2\times2\) สมมาตรจึงต้องมีรูป \(\begin{bmatrix} a & b\\ b & d \end{bmatrix}\) (สมาชิกตำแหน่ง (1,2) เท่ากับตำแหน่ง (2,1) เหมือนภาพสะท้อนข้ามเส้นทแยง) · ส่วนการตรวจใช้เกณฑ์ปริภูมิย่อยสองข้อของทฤษฎีบท 5.1.3 เหมือนตัวอย่างที่ 1
  2. \(W\): เช็กเวกเตอร์ศูนย์ เวกเตอร์ศูนย์ของ \(M_2(\mathbb{R})\) คือเมทริกซ์ศูนย์ \(\begin{bmatrix} 0 & 0\\ 0 & 0 \end{bmatrix}\) ซึ่งสมมาตร ✓ เพราะสลับแถวกับหลักแล้วได้ตัวเอง (\(0^T = 0\)) → \(\vec{0} \in W\) ✓
  3. \(W\): เช็กปิดการรวมเชิงเส้น ให้ \(A, B \in W\) (คือ \(A^T = A\) และ \(B^T = B\)) และ \(k \in \mathbb{R}\) ใช้สมบัติทรานสโพส: ทรานสโพสของผลบวก = ผลบวกของทรานสโพส และ \((kB)^T = kB^T\) จึงได้ \[ (A + kB)^T = A^T + kB^T = A + kB \;\checkmark \] เพราะแทน \(A^T = A\) และ \(B^T = B\) (สมบัติของสมาชิกใน \(W\)) ลงในผลลัพธ์ได้ตรง ๆ → \(A + kB\) ก็สมมาตร → ปิดการรวมเชิงเส้น ✓ → \(W\) เป็นปริภูมิย่อยของ \(M_2(\mathbb{R})\)
  4. \(U = \{A : \det A = 0\}\): เวกเตอร์ศูนย์ผ่านจริง แต่ยังสรุปไม่ได้ \(\det\,\vec{0} = 0\) → \(\vec{0} \in U\) ✓ (เพราะเมทริกซ์ศูนย์มีดีเทอร์มิแนนต์เป็นศูนย์) — ข้อนี้ผ่าน จุดตัดสินจึงอยู่ที่ข้อ "ปิดการบวก" ขั้นต่อไป
  5. \(U\): หาตัวอย่างค้านการบวก เลือกเมทริกซ์ทแยงง่าย ๆ สองตัว \[ A = \begin{bmatrix} 1 & 0\\ 0 & 0 \end{bmatrix}, \qquad B = \begin{bmatrix} 0 & 0\\ 0 & 1 \end{bmatrix} \] คิดดีเทอร์มิแนนต์ด้วยสูตร \(ad - bc\) (มุมซ้ายบนคูณมุมขวาล่าง ลบด้วยมุมขวาบนคูณมุมซ้ายล่าง): \(\det A = (1)(0) - (0)(0) = 0\) ✓ และ \(\det B = (0)(0) - (0)(1) = 0\) ✓ → ทั้งคู่เป็นสมาชิกของ \(U\) จริง

  3. \(W_1 \cap W_2\): บังคับเงื่อนไขทั้งสองพร้อมกัน เวกเตอร์ทั่วไปใน \(W_1\) คือ \((a - b, a, b)^T\) (เกิดจากแทน \(x_1 = a, x_2 = b\)) — จะอยู่ใน \(W_2\) ด้วยต้องมีสมาชิกตำแหน่งที่ 2 เท่ากับตำแหน่งที่ 3 (นี่คือเงื่อนไขนิยามของ \(W_2\)): \(a = b\) → แทนกลับ: เวกเตอร์กลายเป็น \((a - a, a, a)^T = (0, a, a)^T = a(0,1,1)^T\) \[ W_1 \cap W_2 = \operatorname{Span}\{(0,1,1)^T\}, \qquad \dim(W_1 \cap W_2) = 1 \] (สมาชิกไม่ใช่ศูนย์มีเพียงแบบเดียวคือทวีคูณของ \((0,1,1)^T\) → เซตเวกเตอร์ตัวเดียวที่ไม่ใช่ศูนย์อิสระโดยอัตโนมัติ → เป็นฐานหลัก → มิติ 1)
  4. ตรวจด้วยสูตรมิติ (ทฤษฎีบท 5.1.6) \[ \dim(W_1+W_2) = \dim W_1 + \dim W_2 - \dim(W_1 \cap W_2) = 2 + 2 - 1 = 3 \;\checkmark \] ตรงกับที่หาได้จากการลดรูปพอดี — คำตอบทั้งสองส่วนสอดคล้องกัน → สรุปคำตอบเต็ม: \(W_1 + W_2 = \mathbb{R}^3\) มีมิติ 3 และ \(W_1 \cap W_2 = \operatorname{Span}\{(0,1,1)^T\}\) มีมิติ 1

ตัวอย่าง 5.1.1จากตำราง่ายฟีลด์จำกัด \(\mathbb{F}_p\) — บวก/คูณแล้วเอาเศษจากการหาร
ให้ \(p\) เป็นจำนวนเฉพาะ และ \(\mathbb{F}_p = \{0, 1, \dots, p - 1\}\) สำหรับ \(a\) และ \(b\) ใดๆ ใน \(\mathbb{F}_p\) เรากำหนด \[ a + b = \text{เศษจากการหาร } a + b \text{ ด้วย } p \qquad\qquad a \times b = \text{เศษจากการหาร } ab \text{ ด้วย } p \] จะได้ว่า \((\mathbb{F}_p, +, \times)\) เป็นฟีลด์ที่มีสมาชิกจำนวนจำกัด
อธิบายโจทย์ง่าย ๆ — โจทย์ยกเซต \(\{0, 1, \dots, p-1\}\) มาพร้อมกฎ "บวก/คูณก่อน แล้วเอาเศษจากการหารด้วย \(p\)" (เลขคิดแบบ mod \(p\)) แล้วยืนยันว่ามันเป็นฟีลด์ คือมีสมบัติการบวก/การคูณครบทุกข้อ รวมถึง "หารได้" ทุกตัวที่ไม่ศูนย์ — วิธีทำให้เห็นภาพคือลองกับ \(p = 5\) ให้เห็นตัวเลขจริงทีละสมบัติ
  1. กฎคือ "วนกลับ" ทุกครั้งที่เกิน \(p - 1\) ลอง \(p = 5\): \(3 + 4 = 7\) เศษจากการหาร 7 ด้วย 5 คือ 2 จึงได้ \(3 + 4 = 2\) · \(2 \times 4 = 8\) เศษ 3 · \(4 + 1 = 5\) เศษ 0 — ผลลัพธ์อยู่ใน \(\{0, 1, 2, 3, 4\}\) เสมอ (ปิดการดำเนินการ เพราะเศษจากการหารด้วย 5 เป็นได้แค่ 0 ถึง 4 เท่านั้น)
  2. เอกลักษณ์และตัวผกผัน \(0\) บวกอะไรก็ได้ตัวเดิม (เศษของ \(a + 0\) คือ \(a\) เอง) จึงเป็นเอกลักษณ์การบวก และตัวผกผันการบวกของ \(a\) คือ \(p - a\) (เช่น \(3 + 2 = 5 \to 0\)) · \(1\) คูณอะไรก็ได้ตัวเดิม จึงเป็นเอกลักษณ์การคูณ · ทุก \(a \neq 0\) มีตัวผกผันการคูณ เช่น ของ \(2\) คือ \(3\) เพราะ \(2 \times 3 = 6 \to 1\) และของ \(4\) คือ \(4\) เอง เพราะ \(4 \times 4 = 16 \to 1\)
  3. ทำไม \(p\) ต้องเป็นจำนวนเฉพาะ ลองกับ \(p = 6\) (ไม่เฉพาะ) ดู: \(2 \times 3 = 6 \to 0\) แปลว่ามี "ตัวคูณศูนย์" — ตัวไม่ศูนย์สองตัวคูณกันได้ศูนย์ และ \(2\) ไม่มีตัวผกผันการคูณเลย (\(2\times1 = 2,\; 2\times2 = 4,\; 2\times4 = 8 \to 2,\; 2\times5 = 10 \to 4\) ไม่มีทางได้ 1) สมบัติการหารจึงพัง — เพราะ\(p\) เฉพาะทำให้ \(p\) หาร \(ab\) ลงตัวได้ต่อเมื่อ \(p\) หาร \(a\) หรือ \(b\) ลงตัว ซึ่งเกิดไม่ได้เมื่อทั้งคู่เล็กกว่า \(p\) และไม่ศูนย์
  4. ความสำคัญต่อบทนี้ ทฤษฎีทั้งหมดของหัวข้อ 5.1 (ปริภูมิเวกเตอร์ เมทริกซ์ Span มิติ) ใช้ได้กับฟีลด์ใดก็ได้ จึงมี \(\mathbb{F}_p^n\), \(M_{m,n}(\mathbb{F}_p)\) เป็นปริภูมิเวกเตอร์ด้วย — ฟีลด์จำกัดอย่าง \(\mathbb{F}_2 = \{0, 1\}\) คือพื้นฐานของรหัสแก้ความผิดพลาดและการเข้ารหัสลับในโลกจริง
สรุปคำตอบ: \((\mathbb{F}_p, +, \times)\) เป็นฟีลด์ที่มี \(p\) สมาชิก — การ "เอาเศษ" ยังคงสมบัติเลขคณิตทุกข้อไว้ และความเฉพาะของ \(p\) ทำให้ไม่มีตัวคูณศูนย์ จึงหารได้ทุกสมาชิกที่ไม่ศูนย์
ตัวอย่าง 5.1.2 (1)จากตำราง่ายเมทริกซ์และพหุนามเป็นปริภูมิเวกเตอร์เหนือฟีลด์
จงแสดงว่าเซตต่อไปนี้ พร้อมการบวกและการคูณด้วยสเกลาร์ตามปกติ เป็นปริภูมิเวกเตอร์เหนือฟีลด์ \(\mathbb{F}\) (1) \(M_{m,n}(\mathbb{F})\) = เซตของเมทริกซ์ \(m \times n\) บน \(\mathbb{F}\) ทั้งหมด (4) \(\mathbb{F}_n[x] = \{a_0 + a_1x + a_2x^2 + \cdots + a_nx^n : a_i \in \mathbb{F}\}\) โดย \(p(x) + q(x) = (a_0 + b_0) + (a_1 + b_1)x + \cdots + (a_n + b_n)x^n\) และ \(c(p(x)) = (ca_0) + (ca_1)x + \cdots + (ca_n)x^n\) พร้อมทั้ง \(\mathbb{F}[x] = \bigcup_{n \geq 0} \mathbb{F}_n[x]\)
อธิบายโจทย์ง่าย ๆ — ตำรายกเซตพวกนี้เป็น "แหล่งกำเนิด" ปริภูมิเวกเตอร์หลักของบท วิธีแสดงคือเดินสมบัติตามนิยามทีละข้อ ซึ่งเกือบทุกข้อโยนกลับไปที่สมบัติของสมาชิกในฟีลด์ \(\mathbb{F}\) เอง จุดที่ต้องพิสูจน์เป็นพิเศษคือปิดการบวก — บวกสองสมาชิกแล้วยังอยู่ในเซตเดิมหรือไม่
  1. \(M_{m,n}(\mathbb{F})\): ทำงานทีละช่อง การบวก/คูณสเกลาร์กระทำต่อสมาชิกทีละตำแหน่ง สมบัติทุกข้อ (เปลี่ยนหมู่ สลับที่ เอกลักษณ์ ตัวผกผัน กระจาย) จึงแตกเป็นสมบัติของจำนวนใน \(\mathbb{F}\) ทีละช่อง เช่น สมบัติเปลี่ยนหมู่ที่ช่อง \((i,j)\) คือ \((a_{ij} + b_{ij}) + c_{ij} = a_{ij} + (b_{ij} + c_{ij})\) ซึ่งจริงเพราะสมาชิกเป็นจำนวนในฟีลด์ → เป็นปริภูมิเวกเตอร์ (เวกเตอร์ศูนย์ = เมทริกซ์ศูนย์ ตรงตามบทที่ 1 เพียงแทน \(\mathbb{R}\) ด้วย \(\mathbb{F}\))
  2. \(\mathbb{F}_n[x]\): จุดสำคัญคือดีกรีไม่ขยาย พหุนามดีกรีไม่เกิน \(n\) สองตัว บวกกันแล้วสัมประสิทธิ์รายดีกรี \(a_i + b_i \in \mathbb{F}\) ยังอยู่ครบถึงดีกรี \(n\) (ไม่มีพจน์ใหม่เกิด เพราะไม่มีการคูณพหุนามเข้าด้วยกัน) และ \(ca_i \in \mathbb{F}\) → ปิดทั้งสองการดำเนินการ สมบัติที่เหลือเดินตามเลขคณิตใน \(\mathbb{F}\) เวกเตอร์ศูนย์ = พหุนามศูนย์ → เป็นปริภูมิเวกเตอร์ (ลองจริง: \((1 + x) + (2 - x) = 3\) และ \(2(x - x^2) = 2x - 2x^2\) ยังดีกรีไม่เกิน 2 ทั้งคู่)
  3. มองพหุนามเป็นพิกัด พหุนาม \(a_0 + a_1x + \cdots + a_nx^n\) เทียบตรงกับเวกเตอร์ \((a_0, a_1, \dots, a_n)^T \in \mathbb{F}^{n+1}\) การบวก/คูณสเกลาร์ของพหุนามก็บวก/คูณพิกัดเหมือนกันทุกอย่าง — จึงทำงานใน \(\mathbb{F}_n[x]\) ได้เหมือนทำงานใน \(\mathbb{F}^{n+1}\) เป๊ะ ๆ ซึ่งเป็นทางลัดแก้โจทย์ทุกขอในหัวข้อนี้
  4. \(\mathbb{F}[x]\): ยูเนียนของทุกดีกรี ตามตำรา \(\mathbb{F}[x] = \bigcup_{n \geq 0} \mathbb{F}_n[x]\) คือพหุนามทุกดีกรี — บวกกันได้ทุกคู่ (ดีกรีของผลบวกไม่เกิน max ของสองดีกรี) สัมประสิทธิ์อยู่ใน \(\mathbb{F}\) ตลอด → เป็นปริภูมิเวกเตอร์ที่มีมิติไม่จำกัด (จะเจอฐานหลัก \(\{1, x, x^2, \dots\}\) ในตัวอย่าง 5.1.8)
สรุปคำตอบ: \(M_{m,n}(\mathbb{F})\), \(\mathbb{F}_n[x]\) และ \(\mathbb{F}[x]\) เป็นปริภูมิเวกเตอร์เหนือ \(\mathbb{F}\) ทั้งหมด — และตำราสังเกตเพิ่มว่า \(\mathbb{F}_{n-1}[x] \subset \mathbb{F}_n[x]\) ทุก \(n\) (ดีกรีต่ำกว่าอยู่ในดีกรีสูงกว่าเสมอ)
ตัวอย่าง 5.1.4 ข้อ 2จากตำราง่าย\(\mathbb{F}_n[x]\) เป็นปริภูมิย่อยของ \(\mathbb{F}[x]\)
ให้ \(n\) เป็นจำนวนเต็มบวกหรือศูนย์ จงแสดงว่า \(\mathbb{F}_n[x]\) เป็นปริภูมิย่อยของ \(\mathbb{F}[x]\)
อธิบายโจทย์ง่าย ๆ — ปริภูมิย่อยคือ "ปริภูมิเวกเตอร์เล็กที่ซ่อนอยู่ในใหญ่" โดยใช้การบวก/คูณสเกลาร์เดียวกัน — เพราะใช้การดำเนินการเดียวกัน สมบัติพีชคณิตที่เหลือสืบทอดโดยอัตโนมัติ จึงเหลือเช็กแค่เกณฑ์ปริภูมิย่อย (ทฤษฎีบท 5.1.3) สองข้อ: \(\vec{0}\) อยู่ในเซต และปิดการรวมเชิงเส้น \(p + cq\)
  1. ข้อ (1): เวกเตอร์ศูนย์ พหุนามศูนย์ทุกสัมประสิทธิ์เป็น 0 จึงมีดีกรี "ไม่เกิน \(n\)" (ถือว่าดีกรีเป็น 0 หรือต่ำกว่า) → \(\vec{0} \in \mathbb{F}_n[x]\) ✓
  2. ข้อ (2): ปิดการรวมเชิงเส้น ให้ \(p, q \in \mathbb{F}_n[x]\) และ \(c \in \mathbb{F}\) — พจน์ \(x^k\) ที่ \(k > n\) ของทั้ง \(p\) และ \(q\) มีสัมประสิทธิ์เป็นศูนย์ ใน \(p + cq\) พจน์ดีกรี \(k > n\) จึงมีสัมประสิทธิ์ \(0 + c \cdot 0 = 0\) เช่นกัน (เหตุผล: การบวกและคูณสเกลาร์ไม่สร้างดีกรีใหม่) → ดีกรีของ \(p + cq\) ไม่เกิน \(n\) → \(p + cq \in \mathbb{F}_n[x]\) ✓ (ทดลองจริง: \((1 + x + x^2) + 2(x^2 - x) = 1 - x + 3x^2\) ยังอยู่ใน \(\mathbb{R}_2[x]\))
  3. สรุปตามเกณฑ์ ผ่านสองข้อของทฤษฎีบท 5.1.3 → \(\mathbb{F}_n[x]\) เป็นปริภูมิย่อยของ \(\mathbb{F}[x]\) — รวมกับที่ตำราชี้ไว้ได้ห่วงโซ่ \(\mathbb{F}_0[x] \subset \mathbb{F}_1[x] \subset \mathbb{F}_2[x] \subset \cdots \subset \mathbb{F}[x]\) ซ้อนกันเรื่อยไป แต่ละชั้นมีมิติเพิ่มทีละ 1
สรุปคำตอบ: \(\mathbb{F}_n[x]\) เป็นปริภูมิย่อยของ \(\mathbb{F}[x]\) — กฎจำง่ายที่ใช้ได้กับโจทย์ทั้งหัวข้อ: เงื่อนไขที่ลงท้าย "= 0" มักเป็นปริภูมิย่อย เงื่อนไขที่ลงท้าย "= ค่าอื่น" มักไม่เป็น (จะเห็นฝั่งตรงข้ามในตัวอย่าง 5.1.4 ข้อ 7)
ตัวอย่าง 5.1.8จากตำราง่ายฐานหลักมาตรฐานและมิติที่ต้องจำ
จงแสดงฐานหลักและมิติของปริภูมิเวกเตอร์ต่อไปนี้ (1) \(M_{m,n}(\mathbb{F})\) โดย \(E_{ij}\) แทนเมทริกซ์ที่สมาชิกแถวที่ \(i\) หลักที่ \(j\) เป็น 1 และตัวอื่นเป็น 0 (2) \(\mathbb{F}_n[x]\) (3) \(\mathbb{F}[x]\) (4) \(M_2(\mathbb{R})\) กับเซต \(\left\{ \begin{bmatrix} 1 & 1\\ 1 & 0 \end{bmatrix}, \begin{bmatrix} 1 & 1\\ 0 & 1 \end{bmatrix}, \begin{bmatrix} 0 & 1\\ 1 & 1 \end{bmatrix}, \begin{bmatrix} 1 & 0\\ 1 & 1 \end{bmatrix} \right\}\) (5) \(\mathbb{C} = \{a + bi : a, b \in \mathbb{R}\}\) ในฐานะปริภูมิเวกเตอร์เหนือ \(\mathbb{R}\)
อธิบายโจทย์ง่าย ๆ — ฐานหลัก = เซตที่อิสระเชิงเส้นและแผ่ทั่ว, มิติ = จำนวนสมาชิกของฐานหลัก (ทฤษฎีบท 5.1.5: ฐานหลักทุกอันมีขนาดเท่ากัน) — โจทย์ชุดนี้คือ "ตารางมาตรฐาน" ที่ควรจำ ทุกข้อพิสูจน์ด้วยสองคำถามเท่านั้น: แผ่ทั่วไหม (ทุกสมาชิกแตกเป็นรวมเชิงเส้นได้ไหม) และอิสระไหม (รวมเป็นศูนย์ได้ด้วยน้ำหนักศูนย์เท่านั้นไหม)
  1. (1) เมทริกซ์ \(E_{ij}\) ของ \(M_{m,n}(\mathbb{F})\) แผ่ทั่วเพราะเมทริกซ์ใด ๆ = ผลรวม \(a_{ij}E_{ij}\) (แต่ละช่องหยิบสัมประสิทธิ์ของตำแหน่งตัวเอง) อิสระเพราะรวมเชิงเส้นเป็นศูนย์แล้วมองช่อง \((i,j)\) ได้ \(c_{ij} = 0\) ทันที (แต่ละตัวมี 1 คนละตำแหน่ง) → เป็นฐานหลักมาตรฐาน มี \(mn\) ตัว → \(\dim M_{m,n}(\mathbb{F}) = mn\) · กรณี \(n = 1\) ให้ \(\{\vec{e}_1, \dots, \vec{e}_m\}\) ฐานหลักมาตรฐานของ \(\mathbb{F}^m\)
  2. (2) \(\{1, x, x^2, \dots, x^n\}\) ของ \(\mathbb{F}_n[x]\) แผ่ทั่วเพราะพหุนามใด ๆ = รวมเชิงเส้นตามสัมประสิทธิ์ (\(a_0 \cdot 1 + a_1 \cdot x + \cdots + a_n \cdot x^n\)) อิสระเพราะเทียบสัมประสิทธิ์ทีละดีกรี (พหุนามศูนย์มีสัมประสิทธิ์ทุกดีกรีเป็น 0) → มี \(n + 1\) สมาชิก → \(\dim \mathbb{F}_n[x] = n + 1\) — ระวังกับดัก: ไม่ใช่ \(n\) เพราะต้องนับพจน์คงตัวด้วย
  3. (3) \(\{1, x, x^2, \dots, x^n, \dots\}\) ของ \(\mathbb{F}[x]\) อิสระด้วยเหตุผลเดียวกัน แต่เป็นเซตที่มีสมาชิกไม่จำกัดจำนวน → \(\mathbb{F}[x]\) ไม่มีมิติจำกัด — ปริภูมิเวกเตอร์ตัวแรกที่เจอซึ่งนับฐานหลักไม่จบ
  4. (4) เมทริกซ์ 4 ตัวของ \(M_2(\mathbb{R})\) อ่านสมาชิกตามลำดับตำแหน่ง \((1,1), (1,2), (2,1), (2,2)\) ได้เวกเตอร์ \((1,1,1,0)^T, (1,1,0,1)^T, (0,1,1,1)^T, (1,0,1,1)^T\) กวาดแถวหาดีเทอร์มิแนนต์: \(R_2 - R_1\), \(R_4 - R_1\) → สลับแถว 2–3 → \(R_4 + R_2\), \(R_4 + R_3\) เหลือสามเหลี่ยมบนไดอะกอนัล \(1, 1, -1, 3\) → \(\det = 3 \neq 0\) (คิดเครื่องหมายการสลับแถวหนึ่งครั้ง) → อิสระ 4 ตัว ในปริภูมิที่ \(\dim = 2 \times 2 = 4\) พอดี → เป็นฐานหลัก (และตัวอย่าง 5.1.6(ข) จะพิสูจน์ว่าแผ่ทั่ว — ครบสองเงื่อนไข)
  5. (5) \(\{1, i\}\) ของ \(\mathbb{C}\) เหนือ \(\mathbb{R}\) ทุกจำนวนเชิงซ้อน \(a + bi\) เขียนเป็น \(a \cdot 1 + b \cdot i\) ได้ (แผ่ทั่ว) และ \(a + bi = 0\) บังคับ \(a = 0\) และ \(b = 0\) (อิสระ เพราะส่วนจริงกับส่วนจินตภาพเทียบกันแยกกัน) → เป็นฐานหลัก → \(\dim \mathbb{C} = 2\) เมื่อวัดเหนือ \(\mathbb{R}\) (แต่ \(\mathbb{C}\) เหนือ \(\mathbb{C}\) มีมิติ 1 — มิติขึ้นกับฟีลด์ที่เลือก!)
สรุปคำตอบ: \(\dim M_{m,n}(\mathbb{F}) = mn\) (ฐาน \(E_{ij}\)) · \(\dim \mathbb{F}_n[x] = n + 1\) (ฐาน \(\{1, x, \dots, x^n\}\)) · \(\mathbb{F}[x]\) ไม่มีมิติจำกัด · เมทริกซ์ 4 ตัวข้างต้นเป็นฐานหลักของ \(M_2(\mathbb{R})\) · \(\{1, i\}\) เป็นฐานหลักของ \(\mathbb{C}\) เหนือ \(\mathbb{R}\)
ตัวอย่าง 5.1.2 (2)จากตำรากลางปริภูมิลำดับ \(\mathbb{F}^{\mathbb{N}}\) และปริภูมิฟังก์ชัน \(\mathbb{F}^S\)
จงแสดงว่า (2) \(\mathbb{F}^{\mathbb{N}} = \{(a_n) : a_n \in \mathbb{F} \text{ สำหรับทุกๆ จำนวนนับ } n\}\) ภายใต้ \((a_n) + (b_n) := (a_n + b_n)\) และ \(c(a_n) := (ca_n)\) เป็นปริภูมิเวกเตอร์เหนือ \(\mathbb{F}\) (ปริภูมิลำดับ) (3) \(\mathbb{F}^S = \{f \mid f : S \to \mathbb{F}\}\) ภายใต้ \((f + g)(x) = f(x) + g(x)\) และ \((cf)(x) = cf(x)\) สำหรับทุกๆ \(x \in S\) เป็นปริภูมิเวกเตอร์เหนือ \(\mathbb{F}\) (ปริภูมิฟังก์ชัน)
อธิบายโจทย์ง่าย ๆ — ลำดับคือ "เวกเตอร์ที่มีพิกัดเป็นจำนวนนับไม่จบ" ส่วนฟังก์ชันคือ "เวกเตอร์ที่มีหนึ่งพิกัดต่อจุดใน \(S\)" — ทั้งคู่บวกและคูณสเกลาร์แบบทีละพิกัด สมบัติทุกข้อของนิยามจึงโยนกลับไปที่สมบัติของสมาชิกฟีลด์ \(\mathbb{F}\) ทีละตำแหน่งเหมือนเดิมทุกประการ
  1. ปริภูมิลำดับ บวกทีละตำแหน่ง เวกเตอร์ศูนย์ = ลำดับศูนย์ \((0, 0, 0, \dots)\) ตัวผกผันของ \((a_n)\) คือ \((-a_n)\) — สมบัติเปลี่ยนหมู่/สลับที่/กระจาย อ่านออกจากสมบัติของ \(a_n + b_n\) ทีละตำแหน่ง (เช่น ตำแหน่งที่ \(k\) ของ \((a_n) + (b_n)\) คือ \(a_k + b_k\) ซึ่งเป็นการบวกจำนวนใน \(\mathbb{F}\)) → \(\mathbb{F}^{\mathbb{N}}\) เป็นปริภูมิเวกเตอร์ ตัวอย่างจริง: \((1, \tfrac12, \tfrac13, \dots) + (1, \tfrac12, \tfrac13, \dots) = (2, 1, \tfrac23, \dots)\)
  2. ปริภูมิฟังก์ชัน บวกแบบ "จุดต่อจุด" (pointwise): ที่จุด \(x\) ใด ๆ ค่าของ \(f + g\) คือ \(f(x) + g(x)\) ซึ่งเป็นการบวกใน \(\mathbb{F}\) — เวกเตอร์ศูนย์ = ฟังก์ชันที่ให้ 0 ทุกจุด, ตัวผกผัน = \((-f)(x) = -f(x)\) ทุกสมบัติจึงตรวจที่จุดเดียวแล้วอ้างซ้ำทุกจุดได้ → \(\mathbb{F}^S\) เป็นปริภูมิเวกเตอร์
  3. เห็นภาพว่าสองอย่างคือสิ่งเดียวกัน ถ้า \(S = \{1, 2\}\) ฟังก์ชัน \(f\) คือคู่ \((f(1), f(2))\) เหมือนเวกเตอร์ใน \(\mathbb{F}^2\) ถ้า \(S = \mathbb{N}\) ก็คือลำดับ ถ้า \(S = \mathbb{R}\) ก็คือปริภูมิ \(\mathbb{F}^{\mathbb{R}}\) ที่พหุนาม \(e^x\) และ \(\sin x\) อาศัยอยู่ทั้งหมด — วิชานี้จึงยอมรับ "ฟังก์ชัน = เวกเตอร์" ได้อย่างสบาย และเป็นเวทีของการแปลงเชิงเส้นอย่างการอนุพันธ์ในหัวข้อ 5.2
สรุปคำตอบ: \(\mathbb{F}^{\mathbb{N}}\) (ปริภูมิลำดับ) และ \(\mathbb{F}^S\) (ปริภูมิฟังก์ชัน) เป็นปริภูมิเวกเตอร์เหนือ \(\mathbb{F}\) ทั้งคู่ — เป็นตัวอย่างมิติไม่จำกัดที่สำคัญคู่กับ \(\mathbb{F}[x]\)
ตัวอย่าง 5.1.4 ข้อ 7จากตำรากลางเงื่อนไข \(p(1) = 0\) เป็นปริภูมิย่อย แต่ \(p(0) = 1\) ไม่เป็น
ให้ \(W_1 = \{p(x) \in \mathbb{F}[x] : p(1) = 0\}\) และ \(W_2 = \{p(x) \in \mathbb{F}[x] : p(0) = 1\}\) จะได้ว่า \(W_1\) เป็นปริภูมิย่อยของ \(\mathbb{F}[x]\) แต่ \(W_2\) ไม่เป็นปริภูมิย่อยของ \(\mathbb{F}[x]\) จงแสดงเหตุผลประกอบ
อธิบายโจทย์ง่าย ๆ — เงื่อนไขสองแบบหน้าตาใกล้กันมาก แต่ผลต่างกันสุดขั้ว ตัวตัดสินคือเกณฑ์ปริภูมิย่อย (ทฤษฎีบท 5.1.3): ข้อ (1) เวกเตอร์ศูนย์อยู่ในเซต และข้อ (2) ปิดการรวมเชิงเส้น \(p + cq\) — เงื่อนไข "แทนค่าแล้วได้ 0" รักษาตัวเองได้ ส่วน "แทนค่าแล้วได้ 1" พังทั้งสองข้อ
  1. \(W_1\): ข้อ (1) ผ่าน พหุนามศูนย์ให้ \(0(1) = 0\) ตรงเงื่อนไขพอดี (เพราะพหุนามศูนย์ให้ค่า 0 ทุกจุด) → \(\vec{0} \in W_1\) ✓
  2. \(W_1\): ข้อ (2) ผ่าน ถ้า \(p(1) = q(1) = 0\) แล้ว \((p + cq)(1) = p(1) + cq(1) = 0 + c \cdot 0 = 0\) ✓ — เพราะการแทนค่ากระจายผ่านการบวกและการคูณสเกลาร์ → ปิดการรวมเชิงเส้น → เป็นปริภูมิย่อย (ตัวอย่างสมาชิก: \(x - 1\), \(x^2 - 1\))
  3. \(W_2\): ข้อ (1) พังทันที พหุนามศูนย์ให้ \(0(0) = 0 \neq 1\) → \(\vec{0} \notin W_2\) → ไม่เป็นปริภูมิย่อย — จบการตัดสินที่นี่ ไม่ต้องเช็กข้อ (2)
  4. (\(W_2\) ข้อ (2) ก็พังเช่นกัน) ถ้า \(p(0) = q(0) = 1\) แล้ว \((p + q)(0) = 1 + 1 = 2 \neq 1\) — ผลบวกของสมาชิกสองตัวหลุดออกนอกเซต (เพราะเงื่อนไขค่าคงที่ที่ไม่ใช่ศูนย์ไม่มีทางปิดการบวก: บวกกันทีไรค่าที่จุดนั้นก็ขยับเป็นสองเท่า)
สรุปคำตอบ: \(W_1 = \{p : p(1) = 0\}\) เป็นปริภูมิย่อยของ \(\mathbb{F}[x]\) · \(W_2 = \{p : p(0) = 1\}\) ไม่เป็น — ตามตำราทุกข้อ และสอดคล้องกับกฎ "= 0 มักผ่าน, ≠ 0 มักพัง"
ตัวอย่าง 5.1.9จากตำรากลางหาฐานหลักและมิติของ \(W\) แบบพารามิเตอร์
จงแสดงว่า \(W = \left\{ \begin{bmatrix} a+b & b\\ a-2c & 0 \end{bmatrix} : a, b, c \in \mathbb{R} \right\}\) เป็นปริภูมิย่อยของ \(M_2(\mathbb{R})\) พร้อมทั้งหาฐานหลักและมิติของ \(W\)
อธิบายโจทย์ง่าย ๆ — เซตที่เขียนด้วยพารามิเตอร์ \(a, b, c\) สามตัว ท่ามาตรฐานคือ "รื้อ" สมาชิกออกเป็นส่วนของ \(a\), ของ \(b\), ของ \(c\) จะได้ \(W = \operatorname{Span}\{B_1, B_2, B_3\}\) ซึ่งเป็นปริภูมิย่อยโดยอัตโนมัติตามทฤษฎีบท 5.1.4 (Span เป็นปริภูมิย่อยเสมอ) — เหลือตรวจอิสระเชิงเส้นเพื่อปิดเรื่องฐานหลักและมิติ
  1. แยกพารามิเตอร์ทีละตัวอักษร จัดกลุ่มพจน์ที่มี \(a\), ที่มี \(b\), ที่มี \(c\): \[ \begin{bmatrix} a+b & b\\ a-2c & 0 \end{bmatrix} = a\begin{bmatrix} 1 & 0\\ 1 & 0 \end{bmatrix} + b\begin{bmatrix} 1 & 1\\ 0 & 0 \end{bmatrix} + c\begin{bmatrix} 0 & 0\\ -2 & 0 \end{bmatrix} \] ตรวจทีละช่อง: ช่อง (1,1) รวมได้ \(a + b\) ✓ ช่อง (2,1) รวมได้ \(a - 2c\) ✓ → \(W = \operatorname{Span}\{B_1, B_2, B_3\}\) → เป็นปริภูมิย่อยของ \(M_2(\mathbb{R})\) ตามทฤษฎีบท 5.1.4
  2. ตรวจอิสระเชิงเส้น ให้ \(xB_1 + yB_2 + zB_3 = \begin{bmatrix} 0 & 0\\ 0 & 0 \end{bmatrix}\) เทียบสมาชิกทีละช่อง: \(x + y = 0\) (ช่อง 1,1), \(y = 0\) (ช่อง 1,2), \(x - 2z = 0\) (ช่อง 2,1), \(0 = 0\) (ช่อง 2,2) — ไล่ตามลำดับที่ข้อมูลไหล: \(y = 0\) → \(x = 0\) → \(z = 0\) → น้ำหนักต้องเป็นศูนย์ทั้งหมด → อิสระเชิงเส้น (ช่อง (2,2) เป็น \(0 = 0\) ไม่บังคับอะไร เพราะทั้งสามเมทริกซ์มีช่องนี้เป็นศูนย์หมด)
  3. สรุปฐานหลักและมิติ อิสระ (ขั้นที่แล้ว) + แผ่ทั่ว (จากการแยกพารามิเตอร์) = ครบนิยามฐานหลัก → \(\left\{ \begin{bmatrix} 1 & 0\\ 1 & 0 \end{bmatrix}, \begin{bmatrix} 1 & 1\\ 0 & 0 \end{bmatrix}, \begin{bmatrix} 0 & 0\\ -2 & 0 \end{bmatrix} \right\}\) เป็นฐานหลักหนึ่งของ \(W\) → \(\dim W = 3\) (ตรงกับจำนวนพารามิเตอร์ \(a, b, c\) พอดี — เครื่องตรวจความสมเหตุสมผลที่ดี)
สรุปคำตอบ: \(W\) เป็นปริภูมิย่อยของ \(M_2(\mathbb{R})\) มีฐานหลักดังกล่าว และ \(\dim W = 3\)
ตัวอย่าง 5.1.5จากตำรากลางอยู่ใน Span หรือไม่ — เทียบสัมประสิทธิ์เป็นระบบ
จงพิจารณาว่าพหุนามต่อไปนี้อยู่ในปริภูมิย่อย \[ W = \operatorname{Span}\{x^3 - 2x^2 - 5x - 3,\; 3x^3 - 5x^2 - 4x - 9\} \] ของ \(\mathbb{R}[x]\) หรือไม่ เพราะเหตุใด (ก) \(2x^3 - 2x^2 + 12x - 6\)    (ข) \(3x^3 - 2x^2 + 7x + 8\)
อธิบายโจทย์ง่าย ๆ — "อยู่ใน Span" แปลว่ามีน้ำหนัก \(a, b\) ที่ \(a \cdot\) (ตัวแรก) \(+ b \cdot\) (ตัวหลัง) = เป้าหมาย — พหุนามเท่ากันเมื่อสัมประสิทธิ์ทุกดีกรีเท่ากัน จึงเทียบทีละดีกรีได้ระบบ 4 สมการ 2 ตัวแปร (สมการเกิน) — ถ้าแก้ได้ครบทุกสมการ = อยู่ใน \(W\) ถ้าสมการไหนขัดแย้ง = ไม่อยู่ จบทันที
  1. เขียนพิกัดสัมประสิทธิ์ (คงตัว, \(x\), \(x^2\), \(x^3\)) เวกเตอร์ฐาน \(\vec{v}_1 = (-3, -5, -2, 1)^T\), \(\vec{v}_2 = (-9, -4, -5, 3)^T\) — สังเกตตั้งแต่ตรงนี้ว่าทั้งคู่มีอัตราส่วน \(x^3\) : คงตัว = \(1 : -3\) เท่ากัน (จะเป็นกุญแจของข้อ (ข))
  2. (ก) ตั้งระบบแล้วแก้ เป้าหมาย \((-6, 12, -2, 2)^T\): พจน์ \(x^3\) ให้ \(a + 3b = 2\) พจน์คงตัวให้ \(-3a - 9b = -6\) ซึ่งเป็นสมการเดียวกันคูณ \(-3\) (สอดคล้อง ไม่ขัด) พจน์ \(x\) ให้ \(-5a - 4b = 12\) แทน \(a = 2 - 3b\): \(-10 + 15b - 4b = 12 \Rightarrow 11b = 22 \Rightarrow b = 2,\; a = -4\) ตรวจพจน์ \(x^2\): \(-2(-4) - 5(2) = 8 - 10 = -2\) ✓ ครบทุกดีกรี \[ 2x^3 - 2x^2 + 12x - 6 = -4\,(x^3 - 2x^2 - 5x - 3) + 2\,(3x^3 - 5x^2 - 4x - 9) \;\Longrightarrow\; \text{(ก) อยู่ใน } W \]
  3. (ข) ระบบขัดแย้งทันที เป้าหมาย \((8, 7, -2, 3)^T\): พจน์ \(x^3\) ให้ \(a + 3b = 3\) พจน์คงตัวให้ \(-3a - 9b = 8\) แต่คูณสมการแรกด้วย \(-3\) ได้ \(-3a - 9b = -9\) — ขัดกับ \(8\) โดยตรง (\(-9 \neq 8\)) → ไม่มีน้ำหนัก \(a, b\) ใดทำได้ → ไม่อยู่ใน \(W\) (ตรวจด้วย python3/numpy: ลดรูปเมทริกซ์พิกัดเพิ่มคอลัมน์เป้าหมาย แรงก์เป็น 3 มากกว่าแรงก์เดิม 2 → ระบบไม่ต้องกัน)
  4. มุมมองเร็วด้วยอัตราส่วน ทุกเวกเตอร์ใน \(W\) มีอัตราส่วน \(x^3\) : คงตัว = \(1 : -3\) (รวมเชิงเส้นรักษาสัดส่วนของพจน์ที่ทุกฐานเหมือนกัน) — ข้อ (ก) ให้ \(2 : -6 = 1 : -3\) พอดี จึงมีหวัง ข้อ (ข) ให้ \(3 : 8\) ไม่ใช่ \(1 : -3\) จึงตัดสินได้ตั้งแต่สองสมการแรก

อธิบายโจทย์ง่าย ๆ — อยากพิสูจน์ว่า Span ของเวกเตอร์ \(n\) ตัวครอบปริภูมิมิติ \(n\) ทั้งปริภูมิ — ทางลัดคือพิสูจน์อิสระเชิงเส้น แล้วสรุปเป็นฐานหลัก (อิสระ + จำนวนครบมิติ → แผ่ทั่วโดยอัตโนมัติ) เครื่องมือตรวจคือเมทริกซ์พิกัด + ดีเทอร์มิแนนต์

(ก) เขียนพิกัดแล้วขยายดีเทอร์มิแนนต์ พิกัด (คงตัว, \(x\), \(x^2\)): \((-2, 3, 1)^T, (-3, 5, 2)^T, (4, -4, -1)^T\) ประกอบเป็นหลักแล้วขยายโคแฟกเตอร์ที่แถวแรก: \[ \det\begin{bmatrix} -2 & -3 & 4\\ 3 & 5 & -4\\ 1 & 2 & -1 \end{bmatrix} = -2\,(5(-1) - (-4)(2)) + 3\,(3(-1) - (-4)(1)) + 4\,(3(2) - 5(1)) = -2(3) + 3(1) + 4(1) = 1 \neq 0 \] → อิสระเชิงเส้น 3 ตัว ใน \(\mathbb{R}_2[x]\) ที่ \(\dim = 3\) → เป็นฐานหลัก → Span ครอบทั้ง \(\mathbb{R}_2[x]\) (ทำไมจำนวนครบมิติช่วยได้: ถ้ามันพึ่งพากัน จะเหลือแผ่ทั่วด้วยน้อยกว่า 3 มิติ ขัดกับ \(\dim \mathbb{R}_2[x] = 3\))

ตัวอย่าง 5.1.7 (ก, ง)จากตำรากลางอิสระเชิงเส้น: พหุนามและเมทริกซ์
จงพิจารณาว่าเซตต่อไปนี้เป็นเซตอิสระเชิงเส้น หรือไม่ เพราะเหตุใด (ก) \(\{x^2 + 3x - 2,\; 2x^2 + 5x - 3,\; -x^2 - 4x + 4\}\) ใน \(\mathbb{R}_2[x]\) (ง) \(\left\{ \begin{bmatrix} 1 & 1\\ 1 & 0 \end{bmatrix}, \begin{bmatrix} 1 & 1\\ 0 & 1 \end{bmatrix}, \begin{bmatrix} 0 & 1\\ 1 & 1 \end{bmatrix}, \begin{bmatrix} 1 & 0\\ 1 & 1 \end{bmatrix} \right\}\) ใน \(M_2(\mathbb{R})\)
อธิบายโจทย์ง่าย ๆ — อิสระเชิงเส้น = รวมเชิงเส้นเป็นศูนย์ได้ด้วยน้ำหนักศูนย์เท่านั้น — แปลงเวกเตอร์เป็นพิกัด (สัมประสิทธิ์พหุนาม หรือสมาชิกเมทริกซ์) แล้วแก้ระบบ "รวมเชิงเส้น = ศูนย์" เหมือนบทที่ 1 ทุกอย่าง ทางลัดเมื่อจำนวนเวกเตอร์ครบมิติพอดี: ดีเทอร์มิแนนต์ไม่ศูนย์ = อิสระทันที
  1. (ก) ตั้งสมการเทียบสัมประสิทธิ์ \(a(x^2 + 3x - 2) + b(2x^2 + 5x - 3) + c(-x^2 - 4x + 4) = 0 + 0x + 0x^2\): \[ \begin{aligned} x^2:\; a + 2b - c &= 0\\ x:\; 3a + 5b - 4c &= 0\\ \text{คงตัว: } -2a - 3b + 4c &= 0 \end{aligned} \]
  2. (ก) แก้ระบบ จากสมการแรก \(c = a + 2b\) แทนในสมการที่สอง: \(3a + 5b - 4a - 8b = -a - 3b = 0 \Rightarrow a = -3b\) แล้ว \(c = -3b + 2b = -b\) แทนในสมการที่สาม: \(-2(-3b) - 3b + 4(-b) = 6b - 3b - 4b = -b = 0 \Rightarrow b = 0\) → \(a = c = 0\) → น้ำหนักต้องศูนย์ทั้งหมด → อิสระเชิงเส้น (ทางลัด: เมทริกซ์พิกัดมี \(\det = 1 \neq 0\) จากตัวอย่าง 5.1.6(ก) — ได้ข้อสรุปเดียวกัน)
  3. (ง) ใช้ทางลัดดีเทอร์มิแนนต์ พิกัด 4 ตัวคือ \((1,1,1,0)^T, (1,1,0,1)^T, (0,1,1,1)^T, (1,0,1,1)^T\) — จำนวน 4 ตัว = \(\dim M_2(\mathbb{R}) = 4\) พอดี จึงใช้ดีเทอร์มิแนนต์ตัดสินได้: \(\det = 3 \neq 0\) (การกวาดแถวเต็ม ๆ อยู่ในตัวอย่าง 5.1.6(ข)) → อิสระเชิงเส้น (ถ้าต้องการแก้ตรง ๆ ก็ตั้งรวมเชิงเส้นเท่าศูนย์ได้ 4 สมการ 4 ตัวแปร ซึ่งมีเฉพาะเฉลยศูนย์)
  4. เชื่อมโยงเป็นฐานหลัก เซต (ก) แผ่ทั่ว (จาก 5.1.6(ก)) + อิสระ (ข้อนี้) = ฐานหลักของ \(\mathbb{R}_2[x]\) เซต (ง) ก็เป็นฐานหลักของ \(M_2(\mathbb{R})\) เช่นเดียวกัน — ตำราจัดคู่ตัวอย่างนี้กับ 5.1.6 ไว้ให้เห็นว่า "แผ่ทั่ว + อิสระ = ฐานหลัก" ทำงานยังไง
สรุปคำตอบ: (ก) และ (ง) เป็นเซตอิสระเชิงเส้นทั้งคู่ — ระบบ "รวมเชิงเส้น = ศูนย์" มีเพียงเฉลยน้ำหนักศูนย์ทุกตัว (ดีเทอร์มิแนนต์ \(1\) และ \(3\) ตามลำดับ)
ตัวอย่าง 5.1.7 (ข, ค)จากตำรายากอิสระเชิงเส้นของฟังก์ชัน — อนุพันธ์และอัตลักษณ์ตรีโกณ
จงพิจารณาว่าเซตต่อไปนี้เป็นเซตอิสระเชิงเส้น หรือไม่ เพราะเหตุใด (ข) \(\{e^x, \sin x\}\) ใน \(\mathbb{R}^{\mathbb{R}}\)    (ค) \(\{1, \sin^2 x, \cos 2x\}\) ใน \(\mathbb{R}^{\mathbb{R}}\)
อธิบายโจทย์ง่าย ๆ — ในปริภูมิฟังก์ชัน \(\mathbb{R}^{\mathbb{R}}\) "เท่ากัน" แปลว่าเท่ากันทุกจุด \(x\) ไม่ใช่บางจุด — ตั้ง \(c_1 f + c_2 g + c_3 h = 0\) (ฟังก์ชันศูนย์) แล้วหาน้ำหนัก สำหรับ \(e^x\) การอนุพันธ์ช่วยสร้างสมการเพิ่ม ส่วนฟังก์ชันตรีโกณมักมีอัตลักษณ์ซ่อนอยู่ให้จับความเชิงพึ่งพา
  1. (ข) ตั้งสมการแล้วอนุพันธ์ \(c_1 e^x + c_2 \sin x = 0\) ต้องจริงทุก \(x\) — อนุพันธ์ทั้งสองข้างได้ (ทำได้เพราะถ้าฟังก์ชันเท่ากันทุกจุด อนุพันธ์ก็เท่ากันทุกจุด): \(c_1 e^x + c_2 \cos x = 0\)
  2. (ข) เลือกจุดให้ตัวใดตัวหนึ่งดับ แทน \(x = 0\) ในสมการเดิม: \(c_1 \cdot 1 + c_2 \cdot 0 = 0 \Rightarrow c_1 = 0\) (เลือกจุดนี้เพราะ\(\sin 0 = 0\) กำจัด \(c_2\) ทิ้ง) แทน \(c_1 = 0\) กลับ: \(c_2 \sin x = 0\) ทุก \(x\) เลือก \(x = \tfrac{\pi}{2}\): \(c_2 = 0\) → น้ำหนักศูนย์ทั้งคู่ → อิสระเชิงเส้น
  3. (ค) จับอัตลักษณ์ทันที รู้จากตรีโกณมิติว่า \(\cos 2x = 1 - 2\sin^2 x\) จัดรูป: \(1 - 2\sin^2 x - \cos 2x = 0\) — นี่คือรวมเชิงเส้นของสามฟังก์ชันในเซตที่ได้ฟังก์ชันศูนย์ โดยน้ำหนัก \((1, -2, -1)\) ไม่เป็นศูนย์เลย → เป็นเชิงพึ่งพา (linearly dependent) (ตรวจด้วยตัวเลข: ที่ \(x = 0\): \(1 - 0 - 1 = 0\) ✓ ที่ \(x = \tfrac{\pi}{2}\): \(1 - 2 - (-1) = 0\) ✓ จริงทุกจุดเพราะเป็นอัตลักษณ์)
  4. บทเรียนของข้อ (ค) ความเป็นอิสระใน \(\mathbb{R}^{\mathbb{R}}\) ไม่ได้ดูที่กราฟ "หน้าตาต่างกัน" แต่ดูที่อัตลักษณ์ — สามฟังก์ชันหน้าตาคนละแบบ แต่ผูกกันด้วยสมการ \(\cos 2x = 1 - 2\sin^2 x\) เพียงสมการเดียวก็พึ่งพากันแล้ว

ตัวอย่าง 5.1.10จากตำรายากฐานหลักและมิติของ \(W_1 + W_2\) และ \(W_1 \cap W_2\)
กำหนดให้ \[ W_1 = \{(x_1 - x_2,\; x_1,\; x_2) : x_1, x_2 \in \mathbb{R}\} \quad\text{และ}\quad W_2 = \{(x_1, x_2, x_3) \in \mathbb{R}^3 : x_2 = x_3\} \] เป็นปริภูมิย่อยของ \(\mathbb{R}^3\) จงหาฐานหลักและมิติของ \(W_1 + W_2\) และ \(W_1 \cap W_2\)
อธิบายโจทย์ง่าย ๆ — ผลบวก \(W_1 + W_2 = \{\vec{w}_1 + \vec{w}_2\}\) คือทุกผลบวกที่เป็นไปได้ ทางลัดคือรวมฐานหลักสองอันเป็นกองเดียวแล้วลดรูปเหลือเฉพาะตัวหลัก · ภาวะเชิงตัด \(W_1 \cap W_2\) คือเวกเตอร์ที่เข้าเงื่อนไขทั้งสองเซตพร้อมกัน จึงแทนรูปพารามิเตอร์ของฝั่งหนึ่งลงในเงื่อนไขอีกฝั่ง — ปิดท้ายตรวจด้วยสูตรมิติ \(\dim(W_1 + W_2) = \dim W_1 + \dim W_2 - \dim(W_1 \cap W_2)\) (ทฤษฎีบท 5.1.6)
  1. ฐานหลักเริ่มต้นของแต่ละตัว \(W_1\): \((x_1 - x_2, x_1, x_2)^T = x_1(1,1,0)^T + x_2(-1,0,1)^T\) → ฐานหลัก \(\{(1,1,0)^T, (-1,0,1)^T\}\) · \(W_2\): เงื่อนไข \(x_2 = x_3\) ทำให้สมาชิกมีรูป \((x_1, x_2, x_2)^T = x_1(1,0,0)^T + x_2(0,1,1)^T\) → ฐานหลัก \(\{(1,0,0)^T, (0,1,1)^T\}\) — ทั้งคู่อิสระ (แต่ละคู่ไม่ใช่สเกลาร์ของกัน) → \(\dim W_1 = \dim W_2 = 2\)
  2. \(W_1 + W_2\): รวมฐานหลัก 4 ตัวแล้วลดรูป ทุก \(\vec{w}_1 + \vec{w}_2\) เขียนเป็นรวมเชิงเส้นของเวกเตอร์ทั้ง 4 ตัวได้ทันที ประกอบเป็นหลักแล้วลดรูปเหลือหลักตัวหลัก 3 หลัก → \(\dim(W_1 + W_2) = 3 = \dim \mathbb{R}^3\) → \(W_1 + W_2 = \mathbb{R}^3\)
  3. \(W_1 \cap W_2\): บังคับเงื่อนไขร่วม เวกเตอร์ทั่วไปของ \(W_1\) คือ \((a - b, a, b)^T\) จะอยู่ใน \(W_2\) ด้วยต้องมีสมาชิกที่สองเท่ากับที่สาม (เงื่อนไขนิยามของ \(W_2\)): \(a = b\) → แทนกลับ: \((a - a, a, a)^T = a(0,1,1)^T\) → \(W_1 \cap W_2 = \operatorname{Span}\{(0,1,1)^T\}\), \(\dim = 1\) (เวกเตอร์ไม่ศูนย์ตัวเดียวอิสระโดยอัตโนมัติ → เป็นฐานหลัก)
  4. ตรวจด้วยสูตรมิติ (ทฤษฎีบท 5.1.6) \[ \dim(W_1 + W_2) = \dim W_1 + \dim W_2 - \dim(W_1 \cap W_2) = 2 + 2 - 1 = 3 \;\checkmark \] สองคำตอบสอดคล้องกัน — และสังเกตว่า \((0,1,1)^T\) ก็คือฐานหลักตัวที่สองของ \(W_2\) นั่นเอง
สรุปคำตอบ: \(W_1 + W_2 = \mathbb{R}^3\) มีมิติ 3 และ \(W_1 \cap W_2 = \operatorname{Span}\{(0,1,1)^T\}\) มีมิติ 1 — ตรงสูตรมิติ \(2 + 2 - 1 = 3\) พอดี

  2. (ก) มองเพิ่ม: \((0,0)\) ไม่ทำหน้าที่เวกเตอร์ศูนย์ด้วย \((0,0) + (x_1, x_2) = (0 + x_1,\; 0 \cdot x_2) = (x_1, 0) \neq (x_1, x_2)\) เมื่อ \(x_2 \neq 0\) — เพราะการบวกที่กำหนด "คูณ" ตำแหน่งที่สองของตัวสองตัวเข้าด้วยกัน ศูนย์จึงดับพจน์ที่สองทิ้ง → (ก) ไม่เป็นปริภูมิเวกเตอร์
  3. (ข) การบวกดี แต่ \(1 \odot \vec{v}\) พัง \(1 \odot (x_1, x_2) = (1 \cdot x_2,\; 1 \cdot x_1) = (x_2, x_1)\) — การคูณสเกลาร์สลับตำแหน่ง! กลับมาเท่าเดิมได้ก็ต่อเมื่อ \(x_1 = x_2\) ตัวค้านชัด ๆ: \(1 \odot (1, 2) = (2, 1) \neq (1, 2)\) ขัดสมบัติข้อ 5 ของนิยาม (\(1 \odot \vec{v} = \vec{v}\)) → (ข) ไม่เป็นปริภูมิเวกเตอร์
  4. บทเรียนร่วม สมบัติของปริภูมิเวกเตอร์ต้องจริงกับเวกเตอร์ทุกตัวและสเกลาร์ทุกค่า ตัวค้านหนึ่งตัวก็เพียงพอ — และ \(0 \odot \vec{v}\), \(1 \odot \vec{v}\) คือสองจุดเช็กที่เร็วที่สุดเสมอเมื่อเจอการดำเนินการที่กำหนดเอง
สรุปคำตอบ: (ก) และ (ข) ไม่ทำให้ \(V = \mathbb{R}^2\) เป็นปริภูมิเวกเตอร์ — (ก) พังที่ \(0 \odot \vec{v} = (0, x_2) \neq \vec{0}_V\) (ข) พังที่ \(1 \odot \vec{v} = (x_2, x_1) \neq \vec{v}\)
ลองทำ 5.1.1จากตำรากลางเช็กสมบัติการคูณสเกลาร์ข้อที่ 2 — ลองทำเองก่อนดูเฉลย
ให้ \(V = \mathbb{R}^2\) กำหนดการบวกและการคูณด้วยจำนวนจริงบน V โดย \[ (x_1, x_2) + (y_1, y_2) = (x_1 + y_1,\; x_2 + y_2) \qquad c(x_1, x_2) = \left(cx_1,\; \frac{x_2}{c}\right) \text{ ถ้า } c \neq 0 \;\text{ และ }\; 0(x_1, x_2) = (0, 0) \] สำหรับทุกๆ เวกเตอร์ \((x_1, x_2), (y_1, y_2) \in V\) และ \(c \in \mathbb{R}\) จงพิจารณาว่า V เป็นปริภูมิเวกเตอร์เหนือฟีลด์ R หรือไม่ เพราะเหตุใด
อธิบายโจทย์ง่าย ๆ — การบวกเป็นมาตรฐาน (ไม่มีปัญหา) จุดที่ต้องสงสัยคือการคูณสเกลาร์ที่ "คูณตำแหน่งแรก แต่หารตำแหน่งที่สอง" — สมบัติที่น่าจะพังคือข้อ 2 ของนิยาม: \((c_1 + c_2) \odot \vec{v} = c_1 \odot \vec{v} \oplus c_2 \odot \vec{v}\) เลือก \(c_1 = c_2 = 1\) ให้เลขง่ายที่สุด แล้วเทียบสองฝั่ง
  1. ฝั่งซ้าย: รวมสเกลาร์ก่อนแล้วค่อยคูณ \((1 + 1) \odot (x_1, x_2) = 2 \odot (x_1, x_2) = \left(2x_1,\; \tfrac{x_2}{2}\right)\) — ตำแหน่งที่สองต้องหารด้วย \(c = 2\) ตามสูตรที่กำหนด
  2. ฝั่งขวา: คูณทีละครั้งแล้วจึงบวก \(1 \odot (x_1, x_2) = \left(x_1,\; \tfrac{x_2}{1}\right) = (x_1, x_2)\) แล้วบวกแบบมาตรฐาน: \((x_1, x_2) + (x_1, x_2) = (2x_1,\; 2x_2)\)
  3. เทียบสองฝั่งด้วยตัวเลขจริง ตำแหน่งแรกเท่ากัน แต่ตำแหน่งที่สอง \(\tfrac{x_2}{2} \neq 2x_2\) เมื่อ \(x_2 \neq 0\) (หารด้วย 2 กับคูณด้วย 2 ต่างกัน 4 เท่า) — ลอง \(\vec{v} = (0, 2)\): ซ้าย \(2 \odot (0, 2) = (0, 1)\) ขวา \((0, 2) + (0, 2) = (0, 4)\) — \((0,1) \neq (0,4)\) ✗
  4. สรุป สมบัติข้อ 2 พังที่ตัวค้าน \((0, 2)\) → V ไม่เป็นปริภูมิเวกเตอร์เหนือ \(\mathbb{R}\) (เหตุผลเชิงลึก: สูตร "คูณ/หาร" ทำให้ผลของสเกลาร์ 2 ไม่เท่ากับผลของสเกลาร์ 1 สองครั้ง — สมบัติกระจายของสเกลาร์จึงรอดไม่ได้)
สรุปคำตอบ: ไม่เป็นปริภูมิเวกเตอร์ — เพราะ \((1 + 1) \odot (0, 2) = (0, 1)\) แต่ \(1 \odot (0,2) \oplus 1 \odot (0,2) = (0, 4)\) ไม่เท่ากัน

อธิบายโจทย์ง่าย ๆ — ข้อมูลแต่ละคู่ (เวลา \(t\), อุณหภูมิ \(y\)) คือเงื่อนไข \(p(t) = y\) หนึ่งข้อ และ \(\mathbb{R}_2[x]\) มีมิติ 3 (ฐานหลัก \(\{1, t, t^2\}\)) — 3 เงื่อนไข × มิติ 3 = ระบบ 3 สมการ 3 ตัวแปร ที่ทฤษฎีบอกล่วงหน้าว่ามีผลเฉลยชุดเดียว (เวลาไม่ซ้ำกัน) — นี่คือเหตุผลที่ interpolation ผ่านจุดข้อมูล "รู้เลยว่าคำตอบไม่ซ้ำ"
  1. แปลงเงื่อนไขเป็นระบบ ที่ \(t = 0\): \(a = 15\) · ที่ \(t = 1\): \(a + b + c = 18\) · ที่ \(t = 2\): \(a + 2b + 4c = 19\) (การแทนค่าที่จุดต่างกันคือสมการเชิงเส้นในสัมประสิทธิ์ \((a, b, c)\) — เพราะพหุนามเท่ากันเมื่อสัมประสิทธิ์ทุกดีกรีเท่ากัน)
  2. แทน \(a = 15\) แล้วเหลือสองสมการ สมการที่สอง: \(b + c = 3\) · สมการที่สาม: \(2b + 4c = 4\) หารด้วย 2 ได้ \(b + 2c = 2\) (ปรับมาตราให้เลขเล็กก่อนแก้ — การหารทั้งสมการด้วยค่าคงตัวไม่เปลี่ยนผลเฉลย)
  3. แก้สองสมการสองตัวแปร ลบกัน: \((b + 2c) - (b + c) = 2 - 3 \Rightarrow c = -1\) แล้ว \(b = 3 - (-1) = 4\) \[ p(t) = 15 + 4t - t^2 \]
  4. ตรวจทั้งสามจุดและใช้งาน \(p(0) = 15\) ✓ · \(p(1) = 15 + 4 - 1 = 18\) ✓ · \(p(2) = 15 + 8 - 4 = 19\) ✓ — ใช้ประมาณค่ากลางช่วงได้ เช่น ตี 1 ครึ่ง: \(p(1.5) = 15 + 6 - 2.25 = 18.75\) องศา

🔐 เลขตรวจสอบ ISBNใช้จริงกลางฟีลด์จำกัด \(\mathbb{F}_p\) ปกป้องเลขบนสินค้าจริง
เลข ISBN-10 บนหนังสือทุกเล่มมี 10 หลัก โดยหลักที่ \(i\) นับจากซ้ายคูณน้ำหนัก \(11 - i\) แล้วรวมกันต้องหารด้วย 11 ลงตัว (หลักสุดท้ายคือ "เลขตรวจสอบ" ที่ถูกเลือกมาให้เป็นเช่นนั้น) หนังสือเล่มหนึ่งมี 9 หลักแรกคือ 0, 3, 0, 6, 4, 0, 6, 1, 5 จงหาเลขตรวจสอบหลักที่ 10
อธิบายโจทย์ง่าย ๆ — นี่คือเลขคิดใน \(\mathbb{F}_{11} = \{0, 1, \dots, 10\}\) จากตัวอย่าง 5.1.1 ตรง ๆ: "หารด้วย 11 ลงตัว" = เศษจากการหารด้วย 11 เท่ากับ 0 การคำนวณทุกขั้นจึงทำในฟีลด์จำกัด (บวก/คูณแล้วเอาเศษ)
  1. คิดผลรวมถ่วงน้ำหนักของ 9 หลักแรก น้ำหนัก \(10, 9, \dots, 2\): \[ 0(10) + 3(9) + 0(8) + 6(7) + 4(6) + 0(5) + 6(4) + 1(3) + 5(2) = 0 + 27 + 0 + 42 + 24 + 0 + 24 + 3 + 10 = 130 \]
  2. ลดเข้า \(\mathbb{F}_{11}\) \(130 = 11 \times 11 + 9\) → เศษ 9 นั่นคือ \(130 \equiv 9 \pmod{11}\) (เลขคิดแบบตัวอย่าง 5.1.1: บวกเสร็จเอาเศษ)
  3. เลือกเลขตรวจสอบ \(d\) ต้องการ \(9 + d \cdot 1 \equiv 0 \pmod{11}\) → \(d \equiv -9 \equiv 2 \pmod{11}\) → เลขตรวจสอบคือ 2 (ISBN เต็ม: 0-306-40615-2) — ถ้าคำนวณแล้วได้ 10 มาตรฐาน ISBN จะเขียนแทนด้วยตัวอักษร X ซึ่งก็คือสมาชิก 10 ของ \(\mathbb{F}_{11}\) นั่นเอง
  4. ทำไม \(p\) ต้องเป็นจำนวนเฉพาะ ถ้าพิมพ์หลักใดผิด ผลรวมจะคลาดไป \((11 - i)(d - d')\) ใน \(\mathbb{F}_{11}\) ซึ่งเป็นผลคูณของสองตัวที่ไม่ศูนย์ — เพราะ 11 เฉพาะ \(\mathbb{F}_{11}\) ไม่มีตัวคูณศูนย์ (เหมือนที่ตรวจไว้ในตัวอย่าง 5.1.1) ความคลาดจึงไม่มีทาง \(\equiv 0\) ระบบจึงจับพิมพ์ผิดหลักเดียวได้ทุกกรณี (และจับการสลับหลักติดกันได้ด้วย เพราะน้ำหนักทุกตัวต่างกัน mod 11)
เห็นไหมว่า... ฟีลด์จำกัด \(\mathbb{F}_p\) จากตำราไม่ใช่ของแปลกโดด — เลขบนสินค้า บัญชีธนาคาร และบัตรต่าง ๆ ที่คุณสแกนทุกวัน ทำงานด้วย "เลขคิด mod \(p\)" ในฟีลด์จำกัดทั้งนั้น และหลักคิดเดียวกันนี้ขยายต่อเป็นรหัสแก้ความผิดพลาด (QR code อ่านได้แม้มีรอยขีดข่วน) ที่ใช้เวกเตอร์และเมทริกซ์เหนือ \(\mathbb{F}_p\) — ทุกทฤษฎีในหัวข้อ 5.1 ใช้ได้กับโลกเหล่านั้นทันที

  1. เตรียมเงื่อนไขให้ใช้ง่าย \(a + b = c + d\) ย้ายข้างได้เป็น \(a + b - c - d = 0\) — ให้เรียกฟังก์ชัน \(f(A) = a + b - c - d\) ง่าย ๆ เงื่อนไขของ \(W_1\) คือ \(f(A) = 0\) และสังเกตว่า \(f\) เป็น "ผลรวมของ (ค่าคงที่)×(สมาชิก)" ซึ่งเชิงเส้นในสมาชิก
  2. เช็กข้อ (1): เมทริกซ์ศูนย์ แทน \(a = b = c = d = 0\) ลงในเงื่อนไข: \(0 + 0 = 0 + 0\) ✓ (หรือใช้รูป \(f(\vec{0}) = 0 + 0 - 0 - 0 = 0\) ✓) เพราะเมทริกซ์ศูนย์ทุกช่องเป็นศูนย์ เงื่อนไขจึงเป็นจริง → \(\vec{0} \in W_1\) ✓
  3. เช็กข้อ (2): ปิดการรวมเชิงเส้น ให้ \(A = \begin{bmatrix} a & b\\ c & d \end{bmatrix}\) และ \(B = \begin{bmatrix} a' & b'\\ c' & d' \end{bmatrix}\) เป็นสมาชิกใด ๆ ของ \(W_1\) (คือ \(a + b - c - d = 0\) และ \(a' + b' - c' - d' = 0\)) และ \(k \in \mathbb{R}\) พิจารณา \(A + kB = \begin{bmatrix} a + ka' & b + kb'\\ c + kc' & d + kd' \end{bmatrix}\) แล้วคำนวณค่า \(f(A + kB)\) โดยกระจายทีละพจน์: \[ f(A + kB) = (a + ka') + (b + kb') - (c + kc') - (d + kd') \] จัดกลุ่มพจน์ของ \(A\) แยกจากพจน์ของ \(B\): \[ = (a + b - c - d) + k(a' + b' - c' - d') = 0 + k(0) = 0 \;\checkmark \] เพราะทั้งสองวงเล็บเท่ากับศูนย์ตามที่ \(A, B \in W_1\) → \(A + kB \in W_1\) → ปิดการรวมเชิงเส้น ✓
  4. สรุป ผ่านทั้งสองข้อของทฤษฎีบท 5.1.3 → \(W_1\) เป็นปริภูมิย่อยของ \(M_2(\mathbb{R})\) (ตรวจด้วยเมทริกซ์จริง: \(A = \begin{bmatrix} 1 & 2\\ 3 & 0 \end{bmatrix}\) มี \(a + b = 3\) และ \(c + d = 3\) เท่ากัน ✓ จึงอยู่ใน \(W_1\) จริง และ \(2A\) ก็ยังผ่านเงื่อนไขเพราะทั้งสองฝั่งเพิ่มเป็นสองเท่าพร้อมกัน)
ข้อ 2●○○

จงหามิติของปริภูมิเวกเตอร์ต่อไปนี้ (ก) \(M_{2,3}(\mathbb{R})\)   (ข) \(\mathbb{R}_3[x]\)   (ค) \(\mathbb{R}_0[x]\) (พหุนามคงตัว)

คำใบ้
\(\dim M_{m,n} = mn\) และ \(\dim \mathbb{F}_n[x] = n+1\) — ฐานหลักมาตรฐานคืออะไร
แนวคิดและเฉลยแบบละเอียด

แนวคิด: นับจำนวนสมาชิกของฐานหลักมาตรฐาน — ฐานหลัก (basis) = เซตเวกเตอร์ที่อิสระเชิงเส้นและแผ่ทั่วปริภูมิ · มิติ (dimension) = จำนวนเวกเตอร์ในฐานหลัก (ทุกฐานหลักของปริภูมิเดียวกันมีขนาดเท่ากัน — ทฤษฎีบท 5.1.5) จึงนับจากฐานหลักมาตรฐานตัวใดตัวหนึ่งได้เลย

  1. (ก) \(M_{2,3}(\mathbb{R})\) ฐานหลักมาตรฐาน = เมทริกซ์ \(E_{ij}\) ที่มีเลข 1 ในตำแหน่ง \((i,j)\) เดียวและ 0 ที่เหลือ เช่น \(E_{11} = \begin{bmatrix} 1 & 0 & 0\\ 0 & 0 & 0 \end{bmatrix}\) — เมทริกซ์ \(2\times3\) มีตำแหน่งสมาชิกทั้งหมด \(2 \times 3 = 6\) ตำแหน่ง → เมทริกซ์ \(E_{ij}\) มี 6 ตัว และอิสระเชิงเส้น (แต่ละตัวมี 1 คนละตำแหน่ง จึงรวมเชิงเส้นเป็นศูนย์ได้ต่อเมื่อสัมประสิทธิ์เป็นศูนย์หมด) → \(\dim = 6\) (ตรงสูตร \(\dim M_{m,n} = mn = 2\cdot3 = 6\))
  2. (ข) \(\mathbb{R}_3[x]\) นิยาม: พหุนามดีกรีไม่เกิน 3 คือรูป \(a_0 + a_1x + a_2x^2 + a_3x^3\) (เขียนพหุนามในรูปพิกัด \((a_0, a_1, a_2, a_3)\) = ค่าคงตัว, สัมประสิทธิ์ \(x\), สัมประสิทธิ์ \(x^2\), สัมประสิทธิ์ \(x^3\)) — ฐานหลักมาตรฐาน \(\{1, x, x^2, x^3\}\) → \(\dim = 4\) (ตรงสูตร \(\dim \mathbb{F}_n[x] = n + 1 = 3 + 1 = 4\) — ระวังกับดัก: ไม่ใช่ 3 เพราะต้องนับพจน์คงตัวด้วยเสมอ)
  3. (ค) \(\mathbb{R}_0[x]\) (พหุนามคงตัว) สมาชิกคือ \(a_0\) ล้วน ๆ ไม่มีพจน์ \(x\) — ฐานหลัก \(\{1\}\) เพราะทุกตัวเขียนเป็น \(a_0 \cdot 1\) ได้ และเซต \(\{1\}\) อิสระ (รวมเชิงเส้น \(c \cdot 1 = 0\) บังคับ \(c = 0\)) → \(\dim = 1\) (ตรงสูตร \(n + 1 = 0 + 1 = 1\)) — สรุป: (ก) 6, (ข) 4, (ค) 1
ข้อ 3●●●

จงแสดงว่า \(W = \{p(x) \in \mathbb{R}_2[x] : p(1) = 0\}\) เป็นปริภูมิย่อยของ \(\mathbb{R}_2[x]\) พร้อมทั้งหาฐานหลักและมิติของ \(W\)

คำใบ้
\(p = a + bx + cx^2\), เงื่อนไข \(a + b + c = 0 \Rightarrow a = -b - c\) → \(p = b(x - 1) + c(x^2 - 1)\)
แนวคิดและเฉลยแบบละเอียด

แนวคิด: เงื่อนไขเชิงเส้น → ปริภูมิย่อย → แทนเงื่อนไขเพื่อหาฐานหลัก — กลยุทธ์: "เป็นปริภูมิย่อย" ใช้เกณฑ์สองข้อของทฤษฎีบท 5.1.3 เหมือนเดิม ส่วน "ฐานหลัก" ให้เขียนพหุนามทั่วไป \(p = a + bx + cx^2\) แล้วบังคับเงื่อนไข \(p(1) = 0\) เพื่อกำจัดพารามิเตอร์ที่เหลือน้อยที่สุด จากนั้นแยกเป็น Span ต่อด้วยการตรวจอิสระ

  1. เป็นปริภูมิย่อย (เช็กสองข้อตามทฤษฎีบท 5.1.3) (1) พหุนามศูนย์: \(0(1) = 0\) ✓ → \(\vec{0} \in W\) · (2) ถ้า \(p(1) = q(1) = 0\) แล้ว \((p + kq)(1) = p(1) + kq(1) = 0 + k \cdot 0 = 0\) ✓ (เพราะการแทนค่าที่ \(x = 1\) กระจายผ่านการบวกและการคูณสเกลาร์) → ปิดการรวมเชิงเส้น → \(W\) เป็นปริภูมิย่อยของ \(\mathbb{R}_2[x]\)
  2. หาฐานหลัก: บังคับเงื่อนไขกับพหุนามทั่วไป เขียน \(p = a + bx + cx^2\) (พหุนามทั่วไปใน \(\mathbb{R}_2[x]\) — มองเป็นพิกัด \((a, b, c)\) = ค่าคงตัว, สัมประสิทธิ์ \(x\), สัมประสิทธิ์ \(x^2\)) แทน \(x = 1\): \(p(1) = a(1) + b(1) + c(1)^2 = a + b + c = 0\) → แก้หา \(a\): \(a = -b - c\) → แทนกลับแล้วจัดกลุ่มตาม \(b\) กับ \(c\): \[ p = (-b - c) + bx + cx^2 = b(x - 1) + c(x^2 - 1) \;\Longrightarrow\; W = \operatorname{Span}\{x - 1,\; x^2 - 1\} \] (ตรวจการจัดกลุ่ม: พจน์ที่มี \(b\) คือ \(-1 + x = x - 1\) ✓ พจน์ที่มี \(c\) คือ \(-1 + x^2 = x^2 - 1\) ✓) — เงื่อนไข 1 ข้อกำจัดพารามิเตอร์ 1 ตัว เหลือ \(b, c\) สองตัวอิสระ
  3. ตรวจอิสระเชิงเส้น ให้ \(\alpha(x-1) + \beta(x^2-1) = \vec{0}\) กระจาย: \((-\alpha - \beta) + \alpha x + \beta x^2 = 0 + 0x + 0x^2\) เทียบสัมประสิทธิ์ทีละดีกรี (พหุนามเท่ากันเมื่อสัมประสิทธิ์ทุกดีกรีเท่ากัน): พจน์ \(x^2\): \(\beta = 0\) พจน์ \(x\): \(\alpha = 0\) (พจน์คงตัว \(-\alpha - \beta = 0\) เป็นจริงตามอัตโนมัติ) ✓ → อิสระ → รวมกับที่แผ่ทั่วแล้ว เป็นฐานหลัก
  4. สรุป \(\{x - 1, x^2 - 1\}\) เป็นฐานหลักหนึ่งสำหรับ \(W\), \(\dim W = 2\) (ตรวจความสมเหตุสมผล: \(\dim \mathbb{R}_2[x] = 3\) ลบไป 1 เพราะเงื่อนไข \(p(1) = 0\) หนึ่งข้อ → \(3 - 1 = 2\) ✓ และทดลองแทนจริง เช่น \(b = 1, c = 0\): \(p = x - 1\) มี \(p(1) = 0\) ✓)
ข้อ 4●●●

ให้ \(V = \mathbb{R}^2\) กำหนดการดำเนินการ \[ (x_1, x_2) + (y_1, y_2) = (x_1 + y_1,\; x_2 + y_2) \qquad \text{และ} \qquad c(x_1, x_2) = \left(cx_1,\; \frac{x_2}{c}\right) \text{ ถ้า } c \neq 0,\; 0(x_1,x_2) = (0,0) \] จงพิจารณาว่า \(V\) เป็นปริภูมิเวกเตอร์เหนือ \(\mathbb{R}\) หรือไม่ เพราะเหตุใด

คำใบ้
การบวกปกติดี แต่เช็กสมบัติการคูณสเกลาร์ข้อที่ 2: \((c_1 + c_2)\odot\vec{v} = c_1\odot\vec{v} \oplus c_2\odot\vec{v}\) ด้วย \(c_1 = c_2 = 1\)
แนวคิดและเฉลยแบบละเอียด

แนวคิด: เทียบสองฝั่งของสมบัติกระจาย — การบวกของข้อนี้เป็นมาตรฐาน (ไม่มีปัญหา) จุดที่ต้องเช็กคือสมบัติการคูณสเกลาร์ โดยเฉพาะข้อที่ 2: \((c_1 + c_2)\odot\vec{v} = c_1\odot\vec{v} \oplus c_2\odot\vec{v}\) เพราะการคูณสเกลาร์ที่โจทย์กำหนดแปลก (คูณ \(c\) ที่ตำแหน่งแรก แต่หารด้วย \(c\) ที่ตำแหน่งที่สอง) มักพังสมบัติข้อนี้ — เลือก \(c_1 = c_2 = 1\) เพื่อให้เลขง่ายที่สุด

  1. เตรียมสูตรที่โจทย์กำหนด การคูณสเกลาร์: \(c(x_1, x_2) = \left(cx_1,\; \frac{x_2}{c}\right)\) เมื่อ \(c \neq 0\) และ \(0(x_1,x_2) = (0,0)\) — สังเกตให้ดี: "คูณ \(c\)" จะคูณตำแหน่งแรก แต่หารตำแหน่งที่สอง (ส่วนการบวกเป็นแบบมาตรฐานตำแหน่งต่อตำแหน่ง)
  2. ฝั่งซ้าย: \((1 + 1)\odot(x_1, x_2)\) รวมสเกลาร์ก่อน: \(1 + 1 = 2\) แล้วคูณด้วย 2: \[ (1 + 1)\odot(x_1, x_2) = 2\odot(x_1, x_2) = \left(2x_1,\; \frac{x_2}{2}\right) \] (ตำแหน่งแรก \(2x_1\) ตามสูตร ตำแหน่งที่สอง \(\tfrac{x_2}{2}\) เพราะสูตรบอกให้หารด้วย \(c = 2\))
  3. ฝั่งขวา: \(1\odot(x_1,x_2) \oplus 1\odot(x_1,x_2)\) คูณด้วย 1 ก่อน (กรณี \(c = 1 \neq 0\)): \(1\odot(x_1,x_2) = \left(x_1, \tfrac{x_2}{1}\right) = (x_1, x_2)\) แล้วเอาผลมาบวกกันเองแบบมาตรฐาน: \[ 1\odot(x_1,x_2) + 1\odot(x_1,x_2) = (x_1, x_2) + (x_1, x_2) = (2x_1, 2x_2) \]
  4. เทียบสองฝั่ง ตำแหน่งแรกเท่ากัน (\(2x_1 = 2x_1\)) แต่ตำแหน่งที่สองไม่เท่ากัน: \(\tfrac{x_2}{2} \neq 2x_2\) เมื่อ \(x_2 \neq 0\) (เหตุผล: หารด้วย 2 กับคูณด้วย 2 ให้ผลต่างกัน 4 เท่า) — ลองด้วยตัวเลขจริง \(\vec{v} = (0, 2)\): ฝั่งซ้าย \(2\odot(0,2) = (0, \tfrac{2}{2}) = (0, 1)\) ฝั่งขวา \((0,2)+(0,2) = (0, 4)\) — \((0,1) \neq (0,4)\) ✗ → สมบัติข้อ 2 พัง → \(V\) ไม่เป็นปริภูมิเวกเตอร์
  5. สรุป เพราะสมบัติการคูณสเกลาร์ข้อที่ 2 (กระจายผ่านการบวกของสเกลาร์) ล้มเหลวที่ \(\vec{v} = (0,2)\) — ตัวค้านตัวเดียวเพียงพอ — การกำหนดการดำเนินการนี้จึงไม่ทำให้ \(V = \mathbb{R}^2\) เป็นปริภูมิเวกเตอร์เหนือ \(\mathbb{R}\)

คำใบ้

แนวคิดและเฉลยแบบละเอียด

แนวคิด: แก้หาน้ำหนักทั่วไป → แผ่ทั่ว → จำนวนเท่ามิติ → ฐานหลัก — กลยุทธ์: "Span เท่ากับ \(\mathbb{R}_2[x]\)" แปลว่าพหุนามใด ๆ \(a + bx + cx^2\) ต้องเขียนเป็นรวมเชิงเส้นของสามเวกเตอร์นี้ได้ — เราจะแก้หาน้ำหนัก \(\alpha, \beta, \gamma\) ในรูปของ \(a, b, c\) แบบทั่วไป ถ้าแก้ได้เสมอไม่ว่า \(a, b, c\) ใด ๆ = แผ่ทั่ว จากนั้นใช้ข้อเท็จจริง "ในปริภูมิมิติ 3 เซตที่แผ่ทั่วซึ่งมี 3 สมาชิกต้องอิสระเชิงเส้น" เพื่อสรุปเป็นฐานหลัก

  1. ตั้งสมการเวกเตอร์แล้วกระจาย ต้องการ \(\alpha(1-x) + \beta(1+x) + \gamma x^2 = a + bx + cx^2\) กระจายฝั่งซ้ายทีละวงเล็บ: \(\alpha - \alpha x + \beta + \beta x + \gamma x^2\) แล้วจัดกลุ่มตามดีกรี (พจน์คงตัวมาจาก \(1\) ของทั้งสองวงเล็บแรก พจน์ \(x\) มาจาก \(-x\) กับ \(+x\)): \[ (\alpha + \beta) + (-\alpha + \beta)x + \gamma x^2 = a + bx + cx^2 \]
  2. เทียบสัมประสิทธิ์ทีละดีกรี พหุนามสองตัวเท่ากันเมื่อสัมประสิทธิ์ทุกดีกรีเท่ากัน: \[ \text{คงตัว: } \alpha + \beta = a, \qquad x\text{: } -\alpha + \beta = b, \qquad x^2\text{: } \gamma = c \] แก้สองสมการแรก: บวกกันเข้า (ตัว \(\alpha\) หักล้างกัน) \(2\beta = a + b \Rightarrow \beta = \tfrac{a+b}{2}\) แล้วแทนย้อน เช่น \(\alpha = a - \beta = a - \tfrac{a+b}{2} = \tfrac{2a - a - b}{2} = \tfrac{a-b}{2}\) — สรุป \(\beta = \tfrac{a+b}{2},\; \alpha = \tfrac{a-b}{2},\; \gamma = c\) (เศษส่วนเกิดจากการหารด้วย 2 — รวมเศษใช้ตัวส่วนร่วม 2)
  3. สรุปว่าแผ่ทั่ว สูตรน้ำหนักที่ได้ใช้ได้กับ \(a, b, c\) ทุกค่า (ไม่มีการหารด้วยศูนย์ ไม่มีเงื่อนไขซ่อน) → พหุนามใด ๆ ใน \(\mathbb{R}_2[x]\) อยู่ใน Span ได้ → แผ่ทั่ว \(\mathbb{R}_2[x]\) (ตรวจด้วยตัวเลขจริง เช่น \(2 + 3x - x^2\): \(\alpha = \tfrac{2-3}{2} = -\tfrac12, \beta = \tfrac{2+3}{2} = \tfrac52, \gamma = -1\) แล้วแทน: \(-\tfrac12(1-x) + \tfrac52(1+x) - x^2 = (-\tfrac12 + \tfrac52) + (\tfrac12 + \tfrac52)x - x^2 = 2 + 3x - x^2\) ✓ กลับมาได้ตรงเดิม)
  4. อิสระหรือไม่ \(\dim \mathbb{R}_2[x] = 3\) (ฐานหลักมาตรฐาน \(\{1, x, x^2\}\)) และเซตของเรามี 3 สมาชิกที่แผ่ทั่วแล้ว — ในปริภูมิมิติ \(n\) เซตที่แผ่ทั่วซึ่งมี \(n\) สมาชิกเป็นอิสระเชิงเส้นโดยอัตโนมัติ (ถ้าพึ่งเชิงเส้น จะลดเหลือน้อยกว่า 3 ตัวแล้วแผ่ทั่วไม่ได้อีก) (อยากเช็กตรง ๆ ก็ได้: \(\alpha + \beta = 0, -\alpha + \beta = 0, \gamma = 0\) บวกสองสมการแรก \(2\beta = 0 \Rightarrow \beta = 0 \Rightarrow \alpha = 0\) ✓ ทุกค่าเป็นศูนย์)
  5. สรุป แผ่ทั่ว + อิสระเชิงเส้น = ครบนิยามฐานหลัก (เซตเวกเตอร์ที่อิสระเชิงเส้นและแผ่ทั่วปริภูมิ) → เซตนี้เป็นฐานหลักสำหรับ \(\mathbb{R}_2[x]\) (สมาชิก 3 ตัว = \(\dim \mathbb{R}_2[x] = 3\) พอดี)
ข้อ 6●●○

ให้ \(W_1 = \{(x_1, x_2, 0) : x_1, x_2 \in \mathbb{R}\}\) และ \(W_2 = \{(0, x_2, x_3) : x_2, x_3 \in \mathbb{R}\}\) จงหาฐานหลักและมิติของ \(W_1 \cap W_2\) และ \(W_1 + W_2\) แล้วตรวจด้วยสูตรมิติ

คำใบ้
เงื่อนไขร่วม: ตำแหน่งแรก = 0 และตำแหน่งสุดท้าย = 0 → \((0, x_2, 0)^T\)
แนวคิดและเฉลยแบบละเอียด

แนวคิด: จับเงื่อนไขร่วม/รวม — \(W_1 \cap W_2\) ต้องตอบสนองเงื่อนไขของทั้งสองเซตพร้อมกัน (และกัน) ส่วน \(W_1 + W_2\) คือเซตของผลบวก \(\vec{w}_1 + \vec{w}_2\) ทุกรูปแบบ ซึ่งมักขยายใหญ่จนครอบคลุมทั้งปริภูมิ — ปิดท้ายเช็กด้วยสูตรมิติ \(\dim(W_1 + W_2) = \dim W_1 + \dim W_2 - \dim(W_1 \cap W_2)\)

  1. หา \(W_1 \cap W_2\) เวกเตอร์ใน \(W_1\) มีรูป \((x_1, x_2, 0)\) (ตำแหน่งสุดท้ายเป็นศูนย์เสมอ) เวกเตอร์ใน \(W_2\) มีรูป \((0, x_2', x_3)\) (ตำแหน่งแรกเป็นศูนย์เสมอ) — จะอยู่ในทั้งคู่พร้อมกันต้องมีทั้งสองรูปแบบไว้พร้อมกัน → เทียบทีละตำแหน่ง: \(x_1 = 0\) (เพราะต้องเข้ารูปของ \(W_2\)) และ \(x_3 = 0\) (เพราะต้องเข้ารูปของ \(W_1\)) → เหลือเฉพาะตำแหน่งกลางอิสระ: \[ W_1 \cap W_2 = \{(0, x_2, 0)\} = \operatorname{Span}\{(0,1,0)^T\}, \qquad \dim = 1 \] (เวกเตอร์ \((0,1,0)^T\) ตัวเดียวที่ไม่ใช่ศูนย์ → เป็นฐานหลัก → มิติ 1)
  2. หา \(W_1 + W_2\) ตามนิยาม หยิบสมาชิกแต่ละเซตมาบวกกัน: \(\vec{w}_1 + \vec{w}_2 = (x_1, x_2, 0) + (0, x_2', x_3) = (x_1,\; x_2 + x_2',\; x_3)\) — ตำแหน่งแรกได้ \(x_1\) อิสระ ตำแหน่งสุดท้ายได้ \(x_3\) อิสระ และตำแหน่งกลาง \(x_2 + x_2'\) ปรับให้เป็นจำนวนจริงใด ๆ ก็ได้ (เพราะเลือก \(x_2\) ให้เท่ากับค่าที่ต้องการแล้วตั้ง \(x_2' = 0\)) → ได้เวกเตอร์ใน \(\mathbb{R}^3\) ทุกตัว → \(W_1 + W_2 = \mathbb{R}^3\), \(\dim = 3\) (ฐานหลักมาตรฐาน \(\{(1,0,0)^T, (0,1,0)^T, (0,0,1)^T\}\))
  3. ตรวจสูตรมิติ (ทฤษฎีบท 5.1.6) \(\dim W_1 = 2\) (ฐานหลัก \(\{(1,0,0)^T, (0,1,0)^T\}\)) และ \(\dim W_2 = 2\) (ฐานหลัก \(\{(0,1,0)^T, (0,0,1)^T\}\)): \[ \dim(W_1+W_2) = 2 + 2 - 1 = 3 \;\checkmark \] ตรงกับ \(\dim \mathbb{R}^3 = 3\) พอดี — สรุปคำตอบเต็ม: \(W_1 \cap W_2\) มีฐานหลัก \(\{(0,1,0)^T\}\) มิติ 1 และ \(W_1 + W_2 = \mathbb{R}^3\) มีมิติ 3
