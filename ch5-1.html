5.1 ปริภูมิเวกเตอร์และปริภูมิย่อย

ยกระดับ "เวกเตอร์" ให้เป็นนามธรรม — พหุนาม เมทริกซ์ ฟังก์ชัน ก็เป็นเวกเตอร์ได้ทั้งหมด ทุกทฤษฎีจากบทที่ 1–2 (Span, อิสระเชิงเส้น, ฐานหลัก, มิติ) ใช้ได้กับปริภูมิเหล่านี้ทันที

🎯 จุดประสงค์ 📖 บทเรียน ✏️ ตัวอย่างโจทย์ ⚡ สูตรสำเร็จ 🏋️ โจทย์ซ้อมมือ

🎯 เรียนจบหัวข้อนี้ คุณต้องทำสิ่งเหล่านี้ได้

  • บอกตัวอย่างปริภูมิเวกเตอร์ที่สำคัญ: \(\mathbb{F}^n\), \(M_{m,n}(\mathbb{F})\), \(\mathbb{F}_n[x]\), \(\mathbb{F}[x]\), ปริภูมิฟังก์ชัน, ปริภูมิลำดับ
  • ตรวจว่าเซตย่อย (พร้อมการดำเนินการที่กำหนดให้) เป็นปริภูมิเวกเตอร์หรือปริภูมิย่อยหรือไม่
  • ใช้เกณฑ์ปริภูมิย่อย: \(\vec{0} \in W\) และ \(\vec{v}_1 + c\vec{v}_2 \in W\)
  • ตรวจอิสระเชิงเส้น/Span/ฐานหลักใน \(\mathbb{F}_n[x]\) และ \(M_{m,n}(\mathbb{F})\) และหามิติ: \(\dim M_{m,n} = mn\), \(\dim \mathbb{F}_n[x] = n+1\)
  • หาฐานหลักและมิติของ \(W_1 + W_2\) และ \(W_1 \cap W_2\)

📖 บทเรียน

1) ปริภูมิเวกเตอร์ (vector space)

📐 นิยาม (โดยสรุป)

ปริภูมิเวกเตอร์ \((V, \oplus, \odot)\) เหนือฟีลด์ \(\mathbb{F}\) คือเซต \(V\) พร้อมการบวก \(\oplus\) และการคูณสเกลาร์ \(\odot\) ที่สอดคล้องสมบัติ: การบวกปิด/เปลี่ยนหมู่/มีเอกลักษณ์ \(\vec{0}_V\)/สลับที่/มีตัวผกผัน และสมบัติการคูณสเกลาร์ 4 ข้อ (รวมถึง \(1 \odot \vec{v} = \vec{v}\))

ทฤษฎีบท 5.1.1 ให้สมบัติตามมา: \(0\odot\vec{v} = \vec{0}_V\), \((-1)\odot\vec{v} = -\vec{v}\), \(c\odot\vec{0}_V = \vec{0}_V\) — เครื่องมือตรวจ "ไม่ใช่ปริภูมิเวกเตอร์" ที่เร็วที่สุดคือหา \(\vec{0}_V\) หรือเช็ก \(1\odot\vec{v} = \vec{v}\)

💡 ตัวอย่างปริภูมิเวกเตอร์ที่ต้องรู้จัก

• \(\mathbb{F}^n\), \(M_{m,n}(\mathbb{F})\) (เมทริกซ์ \(m\times n\)) — เหมือนบทที่ 1

• \(\mathbb{F}_n[x]\) = พหุนามดีกรีไม่เกิน \(n\) เช่น \(\mathbb{R}_2[x] = \{a_0 + a_1x + a_2x^2\}\) — เปรียบเทียบได้กับ \(\mathbb{F}^{n+1}\) ผ่านสัมประสิทธิ์

• \(\mathbb{F}[x]\) = พหุนามทุกดีกรี (มีมิติไม่จำกัด), ปริภูมิฟังก์ชัน \(\mathbb{R}^{\mathbb{R}}\), ปริภูมิลำดับ \(\mathbb{F}^{\mathbb{N}}\), ผลคูณตรง \(V_1\times\cdots\times V_n\)

2) ปริภูมิย่อย (subspace)

⭐ ทฤษฎีบท 5.1.3 — เกณฑ์ปริภูมิย่อย (ใช้บ่อยที่สุดของบทนี้)

\(W \subseteq V\) เป็นปริภูมิย่อยของ \(V\) ก็ต่อเมื่อ

1. \(\vec{0}_V \in W\)  และ  2. \(\vec{v}_1 + c\vec{v}_2 \in W\) สำหรับทุก \(\vec{v}_1, \vec{v}_2 \in W\), \(c \in \mathbb{F}\) (ปิดการรวมเชิงเส้น)

3) Span อิสระเชิงเส้น ฐานหลัก มิติ — ใช้ได้กับทุกปริภูมิ

⭐ ความรู้เดิม ใช้ใหม่ได้ทันที

Span, อิสระเชิงเส้น, ฐานหลัก (อิสระ + แผ่ทั่ว), มิติ (ฐานหลักทุกอันมีขนาดเท่ากัน — ทฤษฎีบท 5.1.5) นิยามเหมือนบทที่ 1–2 เพียงแต่เวกเตอร์อาจเป็นพหุนาม/เมทริกซ์/ฟังก์ชัน

• \(\dim M_{m,n}(\mathbb{F}) = mn\) (ฐานหลักมาตรฐาน = เมทริกซ์ \(E_{ij}\) ที่มี 1 ตำแหน่ง \((i,j)\))

• \(\dim \mathbb{F}_n[x] = n + 1\) (ฐานหลักมาตรฐาน \(\{1, x, x^2, \dots, x^n\}\))

• \(\mathbb{F}[x]\) มีมิติไม่จำกัด

📐 ผลบวกและภาวะเชิงตัดของปริภูมิย่อย (ทฤษฎีบท 5.1.6)

ถ้า \(W_1, W_2\) เป็นปริภูมิย่อยของ \(V\) แล้ว \(W_1 + W_2 = \{\vec{w}_1 + \vec{w}_2\}\) และ \(W_1 \cap W_2\) เป็นปริภูมิย่อยของ \(V\) ทั้งคู่ และสำหรับมิติจำกัด:

\[ \dim(W_1 + W_2) = \dim W_1 + \dim W_2 - \dim(W_1 \cap W_2) \]
⚠️ กับดักของบทนี้

• เจอการบวก/การคูณสเกลาร์ที่กำหนดให้แปลก ๆ ต้องเช็กสมบัติตามนิยามจริง ๆ ห้ามสันนิษฐาน — จุดพังบ่อย: ไม่มี \(\vec{0}_V\), \(1\odot\vec{v} \neq \vec{v}\), หรือ \((c_1+c_2)\odot\vec{v} \neq c_1\odot\vec{v} \oplus c_2\odot\vec{v}\)

• เงื่อนไขเชิงพีชคณิตแบบ "ไม่เชิงเส้น" (เช่น \(\det A = 0\), \(p(0) = 1\)) มักไม่เป็นปริภูมิย่อย เพราะไม่ปิดการบวก — หาเวกเตอร์ตัวอย่างค้านได้เร็ว

✏️ ตัวอย่างโจทย์

ตัวอย่าง 1ง่ายตรวจปริภูมิย่อยของ \(\mathbb{R}[x]\) (ตัวอย่างคลาสสิกของตำรา)
จงพิจารณาว่า \(W_1 = \{p(x) \in \mathbb{R}[x] : p(1) = 0\}\) และ \(W_2 = \{p(x) \in \mathbb{R}[x] : p(0) = 1\}\) เป็นปริภูมิย่อยของ \(\mathbb{R}[x]\) หรือไม่ เพราะเหตุใด
แนวคิด — เช็ก \(\vec{0}\) ก่อน แล้วเช็กการปิดการรวมเชิงเส้น
  1. \(W_1\) เป็นปริภูมิย่อย พหุนามศูนย์มี \(p(1) = 0\) ✓ และถ้า \(p(1) = q(1) = 0\) แล้ว \((p + cq)(1) = p(1) + cq(1) = 0\) ✓ → ปิดการรวมเชิงเส้น → เป็นปริภูมิย่อย
  2. \(W_2\) ไม่เป็นปริภูมิย่อย พจน์ที่จับต้องได้ทันที: พหุนามศูนย์มี \(p(0) = 0 \neq 1\) → \(\vec{0} \notin W_2\) ✗ (แม้แต่ปิดการบวกก็พัง: \(p, q \in W_2\) แล้ว \((p+q)(0) = 2 \neq 1\))
ตัวอย่าง 2ง่ายตรวจปริภูมิย่อยของ \(M_2(\mathbb{R})\) (ตัวอย่างคลาสสิกของตำรา)
จงพิจารณาว่า \(W = \{A \in M_2(\mathbb{R}) : A \text{ เป็นเมทริกซ์สมมาตร}\}\) และ \(U = \{A \in M_2(\mathbb{R}) : \det A = 0\}\) เป็นปริภูมิย่อยของ \(M_2(\mathbb{R})\) หรือไม่
แนวคิด — เงื่อนไขเชิงเส้น → ปริภูมิย่อย / เงื่อนไขเชิงคูณ (det, กำลังสอง) → มักพังการบวก
  1. \(W\) เป็นปริภูมิย่อย \(\vec{0}\) สมมาตร ✓; ถ้า \(A^T = A, B^T = B\) แล้ว \((A + cB)^T = A^T + cB^T = A + cB\) ✓ → เป็นปริภูมิย่อย
  2. \(U\) ไม่เป็นปริภูมิย่อย หาตัวอย่างค้าน: \(A = \begin{bmatrix} 1 & 0\\ 0 & 0 \end{bmatrix}, B = \begin{bmatrix} 0 & 0\\ 0 & 1 \end{bmatrix}\) ทั้งคู่มี \(\det = 0\) แต่ \(A + B = I_2\) มี \(\det = 1 \neq 0\) → ไม่ปิดการบวก ✗
ตัวอย่าง 3ยากการดำเนินการแปลก ๆ เป็นปริภูมิเวกเตอร์หรือไม่ (ตัวอย่างคลาสสิกของตำรา)
กำหนด \(V = \mathbb{R}^2\) จงพิจารณาว่าการกำหนดการดำเนินการต่อไปนี้ทำให้ \(V\) เป็นปริภูมิเวกเตอร์เหนือ \(\mathbb{R}\) หรือไม่
(ก) \((x_1, x_2) + (y_1, y_2) = (x_1 + y_1, x_2y_2)\) และ \(c(x_1, x_2) = (cx_1, x_2)\)
(ข) \((x_1, x_2) + (y_1, y_2) = (x_1 + y_1, x_2 + y_2)\) และ \(c(x_1, x_2) = (cx_2, cx_1)\)
แนวคิด — หาจุดพังที่เร็วที่สุด: เอกลักษณ์การบวก, \(0\odot\vec{v}\), \(1\odot\vec{v}\) หรือสมบัติกระจาย
  1. (ก) ไม่เป็นปริภูมิเวกเตอร์ เช็ก \(0 \odot \vec{v}\): \(0(x_1, x_2) = (0, x_2) \neq \vec{0}_V = (0, 0)\) สำหรับ \(x_2 \neq 0\) — ขัดทฤษฎีบท 5.1.1(ค) (หรือมองว่าไม่มีเวกเตอร์ศูนย์: ต้องการ \((0,0) + (x_1,x_2) = (x_1, x_2x_2) = (x_1, x_2)\) ทุก \(x_2\) ซึ่งเป็นไปไม่ได้) ✗
  2. (ข) ไม่เป็นปริภูมิเวกเตอร์ การบวกเป็นมาตรฐานดี แต่สมบัติข้อ 5 พัง: \(1 \odot (x_1, x_2) = (x_2, x_1) \neq (x_1, x_2)\) เมื่อ \(x_1 \neq x_2\) ✗ (เช่น \(1\odot(1,2) = (2,1)\))
ตัวอย่าง 4ยากแสดง W เป็นปริภูมิย่อยของ \(M_2(\mathbb{R})\) + หาฐานหลักและมิติ (ตัวอย่างคลาสสิกของตำรา)
จงแสดงว่า \(W = \left\{ \begin{bmatrix} a+b & b\\ a-2c & 0 \end{bmatrix} : a, b, c \in \mathbb{R} \right\}\) เป็นปริภูมิย่อยของ \(M_2(\mathbb{R})\) พร้อมทั้งหาฐานหลักและมิติของ \(W\)
แนวคิด — แยกพารามิเตอร์ให้เห็นว่า \(W = \operatorname{Span}\{B_1, B_2, B_3\}\) → เป็นปริภูมิย่อย → ตรวจอิสระ → ได้ฐานหลัก
  1. แยกพารามิเตอร์ \[ \begin{bmatrix} a+b & b\\ a-2c & 0 \end{bmatrix} = a\begin{bmatrix} 1 & 0\\ 1 & 0 \end{bmatrix} + b\begin{bmatrix} 1 & 1\\ 0 & 0 \end{bmatrix} + c\begin{bmatrix} 0 & 0\\ -2 & 0 \end{bmatrix} = \operatorname{Span}\{B_1, B_2, B_3\} \] โดยทฤษฎีบท 5.1.4 \(W\) เป็นปริภูมิย่อยของ \(M_2(\mathbb{R})\) ✓
  2. ตรวจอิสระเชิงเส้น ให้ \(xB_1 + yB_2 + zB_3 = 0\) เทียบสมาชิก: \(x + y = 0,\; y = 0,\; x - 2z = 0,\; 0 = 0\) → \(y = 0 \Rightarrow x = 0 \Rightarrow z = 0\) → อิสระเชิงเส้น
  3. สรุป \(\left\{ \begin{bmatrix} 1 & 0\\ 1 & 0 \end{bmatrix}, \begin{bmatrix} 1 & 1\\ 0 & 0 \end{bmatrix}, \begin{bmatrix} 0 & 0\\ -2 & 0 \end{bmatrix} \right\}\) เป็นฐานหลักหนึ่งสำหรับ \(W\) และ \(\dim W = 3\)
ตัวอย่าง 5ยาก\(W_1 + W_2\) และ \(W_1 \cap W_2\) (ตัวอย่างคลาสสิกของตำรา)
กำหนด \(W_1 = \{(x_1 - x_2, x_1, x_2) : x_1, x_2 \in \mathbb{R}\}\) และ \(W_2 = \{(x_1, x_2, x_3) \in \mathbb{R}^3 : x_2 = x_3\}\) จงหาฐานหลักและมิติของ \(W_1 + W_2\) และ \(W_1 \cap W_2\)
แนวคิด — เขียนแต่ละ \(W_i\) เป็น Span → รวมฐานหลักได้ \(W_1 + W_2\) → แก้ระบบหา \(W_1 \cap W_2\) → ตรวจด้วยสูตรมิติ
  1. ฐานหลักของแต่ละตัว \[ W_1 = \operatorname{Span}\{(1,1,0)^T, (-1,0,1)^T\}, \qquad W_2 = \operatorname{Span}\{(1,0,0)^T, (0,1,1)^T\} \] (\(\dim W_1 = \dim W_2 = 2\))
  2. \(W_1 + W_2\) รวมเวกเตอร์ 4 ตัว → สร้างเมทริกซ์แล้วลดรูป จะพบว่าเหลือหลักตัวหลัก 3 หลัก → \(\dim(W_1 + W_2) = 3\) → \(W_1 + W_2 = \mathbb{R}^3\) (และเห็นได้จาก \((1,0,0)^T, (0,1,1)^T, (1,1,0)^T\) อิสระ 3 ตัวใน \(\mathbb{R}^3\) พอดี)
  3. \(W_1 \cap W_2\) เวกเตอร์ใน \(W_1\) คือ \((a - b, a, b)^T\) — จะอยู่ใน \(W_2\) ต้องมีสมาชิกตำแหน่ง 2 = ตำแหน่ง 3: \(a = b\) → เวกเตอร์กลายเป็น \((0, a, a)^T = a(0,1,1)^T\) \[ W_1 \cap W_2 = \operatorname{Span}\{(0,1,1)^T\}, \qquad \dim(W_1 \cap W_2) = 1 \]
  4. ตรวจด้วยสูตรมิติ \(\dim(W_1+W_2) = 2 + 2 - 1 = 3\) ✓ ตรงกัน

⚡ สูตรสำเร็จ — ท่าที่ใช้ทำโจทย์หัวข้อนี้

🪜 ท่าหลัก: ตรวจปริภูมิย่อยและหาฐานหลักในปริภูมินามธรรม
  1. ตรวจเป็นปริภูมิย่อย: (1) \(\vec{0} \in W\) (2) ปิดการรวมเชิงเส้น \(\vec{v}_1 + c\vec{v}_2 \in W\) — เงื่อนไขเชิงเส้นผ่าน, เงื่อนไขคูณ/ยกกำลัง/ค่าคงตัว ≠ 0 มักไม่ผ่าน (หาตัวอย่างค้าน)
  2. การดำเนินการแปลก ๆ: เช็กจุดพังเร็ว: มี \(\vec{0}_V\) จริงไหม / \(1\odot\vec{v} = \vec{v}\) ไหม / \((c_1+c_2)\odot\vec{v}\) เท่ากับรวมของแยกไหม
  3. เซตแบบพารามิเตอร์: แยกพารามิเตอร์ → Span → ตรวจอิสระ → ฐานหลักและมิติ
  4. เซตแบบเงื่อนไข: แทนเงื่อนไขลงในพารามิเตอร์ → แยกเวกเตอร์อิสระที่เหลือเป็นฐานหลัก
  5. \(W_1 \cap W_2\): แก้เงื่อนไขทั้งสองพร้อมกัน / \(W_1+W_2\): รวมฐานหลักแล้วลดรูป → ตรวจด้วยสูตร \(\dim(W_1+W_2) = \dim W_1 + \dim W_2 - \dim(W_1\cap W_2)\)
ท่า: จำมิติมาตรฐาน
\(\dim \mathbb{F}^n = n\), \(\dim M_{m,n} = mn\), \(\dim \mathbb{F}_n[x] = n+1\), \(\dim \mathbb{C} = 2\) เหนือ \(\mathbb{R}\) (ฐาน \(\{1, i\}\))
ท่า: พหุนาม ↔ สัมประสิทธิ์
พหุนาม \(a_0 + a_1x + a_2x^2\) ทำงานเหมือนเวกเตอร์ \((a_0, a_1, a_2)^T\) — ลดรูปได้ด้วยเมทริกซ์สัมประสิทธิ์
ท่า: เช็กสมมาตรเป็นปริภูมิย่อย
เซตของเมทริกซ์สมมาตร = ปริภูมิย่อย (ปิด + คูณสเกลาร์) แต่เซตเอกฐาน (det = 0) และ invertible = ไม่เป็น
ท่า: อิสระใน \(\mathbb{F}_n[x]\)
จับสัมประสิทธิ์เป็นเวกเตอร์คอลัมน์แล้วลดรูป — เหมือนบทที่ 1 ทุกอย่าง

แนวคิด: เงื่อนไขเชิงเส้น → มักเป็นปริภูมิย่อย — ยืนยันด้วยเกณฑ์สองข้อ

  1. เมทริกซ์ศูนย์ \(a = b = c = d = 0\): \(0 + 0 = 0 + 0\) ✓ → \(\vec{0} \in W_1\)
  2. ปิดการรวมเชิงเส้น ถ้า \(a+b = c+d\) และ \(a'+b' = c'+d'\) แล้วสำหรับ \(A + kB\) เงื่อนไขกลายเป็น \((a+kb')\)... รวมกัน: \((a + kb') + (b + kb) = (a+b) + k(b+b')\)? — เขียนให้ชัด: สมาชิก \(a+b - c - d\) ของ \(A + kB\) = \((a+b-c-d) + k(a'+b'-c'-d') = 0 + k(0) = 0\) ✓
  3. สรุป ผ่านทั้งสองข้อ → \(W_1\) เป็นปริภูมิย่อยของ \(M_2(\mathbb{R})\)

ข้อ 3●●●

จงแสดงว่า \(W = \{p(x) \in \mathbb{R}_2[x] : p(1) = 0\}\) เป็นปริภูมิย่อยของ \(\mathbb{R}_2[x]\) พร้อมทั้งหาฐานหลักและมิติของ \(W\)

คำใบ้
\(p = a + bx + cx^2\), เงื่อนไข \(a + b + c = 0 \Rightarrow a = -b - c\) → \(p = b(x - 1) + c(x^2 - 1)\)
แนวคิดและเฉลยแบบละเอียด

แนวคิด: เงื่อนไขเชิงเส้น → ปริภูมิย่อย → แทนเงื่อนไขเพื่อหาฐานหลัก

  1. เป็นปริภูมิย่อย \(\vec{0} \in W\) (0(1) = 0 ✓) และ \((p + kq)(1) = p(1) + kq(1) = 0\) ✓ → ปริภูมิย่อย
  2. หาฐานหลัก \(p = a + bx + cx^2\) กับ \(a = -b - c\): \[ p = b(x - 1) + c(x^2 - 1) \;\Longrightarrow\; W = \operatorname{Span}\{x - 1,\; x^2 - 1\} \]
  3. ตรวจอิสระ \(\alpha(x-1) + \beta(x^2-1) = \vec{0}\) เทียบสัมประสิทธิ์: \(x^2\): \(\beta = 0\); \(x\): \(\alpha = 0\) ✓ → อิสระ → เป็นฐานหลัก
  4. สรุป \(\{x - 1, x^2 - 1\}\) เป็นฐานหลักหนึ่งสำหรับ \(W\), \(\dim W = 2\) (ตรวจ: \(3 - 1 = 2\) ลบไป 1 เพราะเงื่อนไข 1 ข้อ)
ข้อ 4●●●

ให้ \(V = \mathbb{R}^2\) กำหนดการดำเนินการ \[ (x_1, x_2) + (y_1, y_2) = (x_1 + y_1,\; x_2 + y_2) \qquad \text{และ} \qquad c(x_1, x_2) = \left(cx_1,\; \frac{x_2}{c}\right) \text{ ถ้า } c \neq 0,\; 0(x_1,x_2) = (0,0) \] จงพิจารณาว่า \(V\) เป็นปริภูมิเวกเตอร์เหนือ \(\mathbb{R}\) หรือไม่ เพราะเหตุใด

คำใบ้
การบวกปกติดี แต่เช็กสมบัติการคูณสเกลาร์ข้อที่ 2: \((c_1 + c_2)\odot\vec{v} = c_1\odot\vec{v} \oplus c_2\odot\vec{v}\) ด้วย \(c_1 = c_2 = 1\)

แนวคิด: เทียบสองฝั่งของสมบัติกระจาย

  1. ฝั่งซ้าย \((1 + 1)\odot(x_1, x_2) = 2\odot(x_1, x_2) = (2x_1, \tfrac{x_2}{2})\)
  2. ฝั่งขวา \[ 1\odot(x_1,x_2) + 1\odot(x_1,x_2) = (x_1, x_2) + (x_1, x_2) = (2x_1, 2x_2) \]
  3. เทียบ \(\tfrac{x_2}{2} \neq 2x_2\) เมื่อ \(x_2 \neq 0\) (เช่น \(\vec{v} = (0, 2)\): ซ้าย \((0, 1)\) ขวา \((0, 4)\)) → สมบัติข้อ 2 พัง → \(V\) ไม่เป็นปริภูมิเวกเตอร์
ข้อ 5●●●

จงแสดงว่า \(\operatorname{Span}\{1 - x,\; 1 + x,\; x^2\} = \mathbb{R}_2[x]\) แล้วสรุปว่าเซตนี้เป็นฐานหลักสำหรับ \(\mathbb{R}_2[x]\) หรือไม่

คำใบ้
แก้ \(\alpha(1-x) + \beta(1+x) + \gamma x^2 = a + bx + cx^2\): \(\alpha = \tfrac{a-b}{2},\; \beta = \tfrac{a+b}{2},\; \gamma = c\)
แนวคิดและเฉลยแบบละเอียด

แนวคิด: แก้หาน้ำหนักทั่วไป → แผ่ทั่ว → จำนวนเท่ามิติ → ฐานหลัก

  1. แก้สมการเวกเตอร์ เทียบสัมประสิทธิ์: คงตัว \(\alpha + \beta = a\); \(x\): \(-\alpha + \beta = b\); \(x^2\): \(\gamma = c\) แก้ได้ \(\beta = \tfrac{a+b}{2},\; \alpha = \tfrac{a-b}{2\) — ได้ผลเฉลยเสมอ → แผ่ทั่ว \(\mathbb{R}_2[x]\)
  2. อิสระหรือไม่ \(\dim \mathbb{R}_2[x] = 3\) และเซตมี 3 สมาชิกที่แผ่ทั่ว → อิสระเชิงเส้นโดยอัตโนมัติ (หรือเช็ก: \(\alpha + \beta = 0, -\alpha + \beta = 0, \gamma = 0\) ให้ทุกค่าเป็นศูนย์ ✓)
  3. สรุป แผ่ทั่ว + อิสระ → เป็นฐานหลักสำหรับ \(\mathbb{R}_2[x]\)
ข้อ 6●●○

ให้ \(W_1 = \{(x_1, x_2, 0) : x_1, x_2 \in \mathbb{R}\}\) และ \(W_2 = \{(0, x_2, x_3) : x_2, x_3 \in \mathbb{R}\}\) จงหาฐานหลักและมิติของ \(W_1 \cap W_2\) และ \(W_1 + W_2\) แล้วตรวจด้วยสูตรมิติ

คำใบ้
เงื่อนไขร่วม: ตำแหน่งแรก = 0 และตำแหน่งสุดท้าย = 0 → \((0, x_2, 0)^T\)
แนวคิดและเฉลยแบบละเอียด

แนวคิด: จับเงื่อนไขร่วม/รวม

  1. \(W_1 \cap W_2\) ต้องอยู่ในทั้งคู่: รูปแบบ \((x_1, x_2, 0)\) และ \((0, x_2', x_3)\) พร้อมกัน → \(x_1 = 0, x_3 = 0\) → \[ W_1 \cap W_2 = \{(0, x_2, 0)\} = \operatorname{Span}\{(0,1,0)^T\}, \qquad \dim = 1 \]
  2. \(W_1 + W_2\) รวมทุก \(\vec{w}_1 + \vec{w}_2 = (x_1, x_2 + x_2', x_3)\) — ปรับพารามิเตอร์ได้ทุก \(\mathbb{R}^3\) (เช่น ตำแหน่งกลางปรับด้วย \(x_2\)) → \(W_1 + W_2 = \mathbb{R}^3\), \(\dim = 3\)
  3. ตรวจสูตรมิติ \(\dim(W_1+W_2) = 2 + 2 - 1 = 3\) ✓ ตรงกับ \(\dim \mathbb{R}^3\)
